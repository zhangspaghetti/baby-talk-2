# SHELL FEATURE

外壳/导航功能模块，应用主导航框架。

## STRUCTURE

```
shell/
└── presentation/
    ├── screens/        # 页面 (4 个)
    └── widgets/        # 组件 (6 个)
```

## WHERE TO LOOK

| 任务 | 位置 | 说明 |
|------|------|------|
| 主页面 | `presentation/screens/` | 4 个主要页面 |
| 导航组件 | `presentation/widgets/` | 6 个导航相关组件 |

## CONVENTIONS

- **路由**：GoRouter 配置
- **导航**：底部导航栏 + 页面切换
