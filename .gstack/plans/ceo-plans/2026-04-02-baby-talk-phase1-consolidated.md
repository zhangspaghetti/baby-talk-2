## Vision

实时双语育儿伴侣，让中国父母在日常场景中自然地对宝宝说英语。
Phase 1 验证核心假设：**父母会不会真的每天对着宝宝说英文短语并坚持下来？**

## Target User

中国父母，25-40 岁，大学英语 CET-4/6，一二线城市。阅读英语 OK，口语弱。
有 0-3 岁宝宝。教育焦虑 + 对孩子的爱是驱动力。

## AI Coach (Ask Coach)

**Phase 1: RAG + LLM**

```
用户输入 (文字 or 语音 via 阿里云 ASR)
  → 后端接收 + 输入过滤 (亵渎/注入检测)
  → Embedding 生成 (阿里云 text-embedding / OpenAI embedding)
  → pgvector 相似度检索 → Top-K 相关短语 (K=5)
  → System prompt 拼接: 育儿方法论 + 检索到的相关短语 + 用户输入
  → LLM 调用 (流式 SSE)
  → 输出过滤 (确保 LLM 响应符合正面育儿方法论)
  → 前端流式显示文字
  → 异步 TTS 生成音频
  → 音频就绪后自动可播放
```

**RAG 架构:**
- Vector DB: pgvector 扩展 (在现有 PostgreSQL 上, 不加新服务)
- Embedding model: 阿里云 text-embedding-v3 (或 OpenAI text-embedding-3-small, Layer 0 spike 决定)
- 索引: 90 种子短语 + coaching tips → 向量化 → phrases_embeddings 表
- 检索策略: cosine similarity, Top-5, score threshold > 0.7
- Fallback: 如果 pgvector 查询失败, 降级为全量种子短语 system prompt (LLM-only 模式)

**延迟策略:** 文字先行 (~2s 感知延迟), TTS 异步 (~5s 后可播放)

**SSE 断连处理 (Eng Review Issue 7):**
- 客户端 SSE 断连后自动重连 (最多 3 次, 指数退避)
- 已收到的文字保留在 UI, 重连后接续拼接
- 3 次重连失败 → 显示已收到的部分文字 + "网络不稳定" 提示

**安全:**
- 后端输入过滤 (亵渎/注入检测, 不依赖客户端)
- 后端输出过滤 (确保 LLM 响应符合正面育儿方法论)
- System prompt 强制正面育儿原则
- Admin 审核页使用独立认证: 环境变量配置的 static Bearer token (Eng Review Issue 9)

**速率限制:** 10 次/用户/天, 服务端计数, UTC midnight 重置

**数据模型:**
```
PhraseRequest {
  id: UUID
  user_id: UUID
  input_text: String
  input_language: String (zh/en)
  generated_phrase_en: String
  generated_phrase_zh: String
  generated_tip: String
  timestamp: DateTime
  was_helpful: Boolean? (null = 未评价)
}
```

### PostgreSQL Schema

```sql
-- 用户表
CREATE TABLE users (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    phone       VARCHAR(20) UNIQUE NOT NULL,
    password_hash VARCHAR(255),          -- 可空，仅密码登录用户
    child_name  VARCHAR(100),
    child_birthdate DATE,
    current_stage INTEGER DEFAULT 1,     -- 1-5，基于生日计算
    created_at  TIMESTAMPTZ DEFAULT now(),
    updated_at  TIMESTAMPTZ DEFAULT now()
);

-- Refresh Token (支持多设备)
CREATE TABLE refresh_tokens (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id     UUID NOT NULL REFERENCES users(id),
    token_hash  VARCHAR(255) NOT NULL,   -- bcrypt hash，不存明文
    expires_at  TIMESTAMPTZ NOT NULL,
    created_at  TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_refresh_tokens_user ON refresh_tokens(user_id);
CREATE INDEX idx_refresh_tokens_expire ON refresh_tokens(expires_at);

-- SMS 验证码: 使用 Redis TTL key，不用 PostgreSQL 表
-- Redis key: sms:{phone} → {code}:{attempts}, TTL 5分钟
-- SMS 发送频率限制 (Eng Review Issue 8):
--   Redis key: sms_rate:{phone} → TTL 60s (同一手机号 1 分钟内不能重发)
--   Redis key: sms_ip_rate:{ip} → counter, TTL 1h (同一 IP 每小时最多 20 条)

-- 种子短语表 (前后端同份数据)
CREATE TABLE phrases (
    id          VARCHAR(100) PRIMARY KEY,  -- e.g. "bath_beginner_01"
    scene_id    VARCHAR(50) NOT NULL,
    difficulty  VARCHAR(20) NOT NULL,      -- beginner, intermediate, advanced
    phrase_en   TEXT NOT NULL,
    phrase_zh   TEXT NOT NULL,
    coaching_tip TEXT,
    sort_order  INTEGER DEFAULT 0,
    created_at  TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_phrases_scene ON phrases(scene_id, difficulty);

-- RAG: 短语向量嵌入表 (pgvector, Eng Review v5 新增)
CREATE EXTENSION IF NOT EXISTS vector;
CREATE TABLE phrase_embeddings (
    phrase_id   VARCHAR(100) PRIMARY KEY REFERENCES phrases(id),
    embedding   vector(1536) NOT NULL,    -- 1536 维度 (OpenAI) 或 1024 (阿里云)
    model       VARCHAR(50) NOT NULL,     -- embedding model 名称
    created_at  TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_phrase_embeddings_vector ON phrase_embeddings
    USING ivfflat (embedding vector_cosine_ops) WITH (lists = 10);
-- 注: 90 条数据, ivfflat lists=10 足够。数据量超 1000 后调整为 sqrt(N)

-- 交互事件 (单一真相来源, append-only)
CREATE TABLE interaction_events (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID NOT NULL REFERENCES users(id),
    event_type      VARCHAR(50) NOT NULL,  -- phrase_played, phrase_spoken,
                                           -- reaction, scene_visit,
                                           -- screen_view, session_start,
                                           -- session_end, feature_use
    scene_id        VARCHAR(50),           -- diaper, bath, feeding, etc.
    phrase_id        VARCHAR(100),          -- 短语标识符
    difficulty      VARCHAR(20),           -- beginner, intermediate, advanced
    reaction_type   VARCHAR(20),           -- looked, spoken, babbled, fussy
    metadata        JSONB,                 -- 额外数据 (analytics 事件详情)
    client_timestamp TIMESTAMPTZ NOT NULL, -- 设备端事件时间
    server_timestamp TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_events_user ON interaction_events(user_id);
CREATE INDEX idx_events_user_time ON interaction_events(user_id, client_timestamp);
CREATE INDEX idx_events_type ON interaction_events(event_type);

-- 计算后的进度 (从 events 聚合, 可重建)
CREATE TABLE user_progress (
    user_id     UUID NOT NULL REFERENCES users(id),
    scene_id    VARCHAR(50) NOT NULL,
    difficulty  VARCHAR(20) NOT NULL,
    mastery_count INTEGER DEFAULT 0,     -- 已掌握短语数
    total_phrases INTEGER NOT NULL,      -- 该场景该难度总短语数
    last_updated TIMESTAMPTZ DEFAULT now(),
    PRIMARY KEY (user_id, scene_id, difficulty)
);

-- 里程碑 (从 events 触发)
CREATE TABLE milestones (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id     UUID NOT NULL REFERENCES users(id),
    type        VARCHAR(50) NOT NULL,    -- first_babble, scene_complete,
                                         -- stage_advance, phrase_count_20, etc.
    scene_id    VARCHAR(50),
    phrase_id   VARCHAR(100),
    achieved_at TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_milestones_user ON milestones(user_id);

-- AI 教练请求
CREATE TABLE phrase_requests (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID NOT NULL REFERENCES users(id),
    input_text      TEXT NOT NULL,
    input_language  VARCHAR(5) DEFAULT 'zh',
    generated_phrase_en TEXT,
    generated_phrase_zh TEXT,
    generated_tip   TEXT,
    was_helpful     BOOLEAN,             -- null=未评价, true/false
    approved        BOOLEAN DEFAULT false, -- 管理员审核状态
    created_at      TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_phrase_req_user ON phrase_requests(user_id, created_at);
CREATE INDEX idx_phrase_req_pending ON phrase_requests(approved) WHERE approved = false;

-- 应用配置
CREATE TABLE app_config (
    key         VARCHAR(100) PRIMARY KEY,
    value       TEXT NOT NULL,
    updated_at  TIMESTAMPTZ DEFAULT now()
);
-- 初始数据: INSERT INTO app_config VALUES ('minimum_supported_version', '1.0.0', now());
```

**Services (业务逻辑):**
| Service | 职责 |
|---------|------|
| AuthService | SMS 发送/验证 (含手机号 1min 重发限制 + IP 级限制, Issue 8), 密码验证, JWT 生成/刷新 |
| SmsService | 阿里云 SMS SDK 封装, 模板管理 |
| SyncService | 事件入库 (**@Transactional 事务包裹**, Issue 3), 触发 progress 重算 |

| CoachService | **RAG 检索 (pgvector, Top-5)** + LLM 调用 + system prompt 构建 + 速率限制检查。pgvector 失败时降级为全量种子短语 prompt |
| EmbeddingService | **新增 (Eng Review v5):** 短语向量化, embedding 存储/更新, pgvector 相似度查询 |
| TtsService | TTS 生成, Redis 缓存引用 (不存 blob, 存 audio URL/hash, Issue 10)。种子短语 TTS 预打包为 Flutter assets |
| ContentFilterService | 输入亵渎/注入检测, 输出育儿合规过滤 |

**Redis 降级策略 (Eng Review Issue 17):**
Redis 不可用时: 限流 fallback 到 ConcurrentHashMap (不精确但可用), SMS 拒绝发送 (安全优先), TTS 跳过缓存直接生成。所有 Redis 调用包裹 try-catch。

## 认证架构

```
用户注册/登录
  → 手机号 + 阿里云 SMS 验证码 (或 账号+密码)
  → 服务端验证
  → 返回 JWT access token (15min) + refresh token (30天)
  → Isar 本地存储 token
  → 每次 API 请求带 Authorization: Bearer <access_token>
  → access token 过期 → interceptor 自动用 refresh token 刷新
  → refresh token 过期 → 跳转登录页
```

## 数据同步 — Event Sourcing

**InteractionEvents 是单一真相来源。**

```
客户端记录 events (Isar 本地存储)
  → 有网时批量上传: POST /api/v1/sync/events
  → 服务端从 events 重新计算 progress (mastery, stage completion)
  → 客户端拉取计算后的 progress: GET /api/v1/sync/progress
```

**不做双向 progress 同步。** Last-write-wins 对聚合数据是灾难性的。

## Onboarding 流程 (Design Review 2026-04-02 确认)

```
欢迎页 → 输入名字 → 输入生日 → 阶段匹配动画
→ "注册保存记录"过渡页 ("小明等着听你说英语")
→ 登录 (手机号+验证码 or 账号密码)
→ PIPL 隐私同意弹窗
→ Smart Home
```

先 Onboarding 后登录，在注册前建立情感投入。

## 情感设计规则 (从 extended-mvp 继承)

1. **永远不评判。** 没有发音评分，没有"失败"。只有"我说了"和"宝宝有反应"。
2. **用孩子名字。** "小明等着听你说"比"请开始练习"有温度 100 倍。
3. **微动画代替数字。** 按"我说了" → 星星粒子，不是 "+1 mastery points"。
4. **进度有温度。** "你这周和小明说了 20 句英语"，不是"mastery: 67%"。

## Anti-Slop 设计规则

禁止：紫色渐变、3 列图标网格、居中万物、统一圆角、装饰性 blob。
要求：单列不等高列表、左对齐为默认、层级化圆角、暖色阴影、孩子名字个性化。
完整规则参见 `baby-talk-extended-mvp.md` "Anti-Slop Design Rules" 章节。
