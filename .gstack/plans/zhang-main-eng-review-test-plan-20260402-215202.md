## Key Interactions to Verify

### Auth
- Invalid phone number format → validation error
- SMS send failure (阿里云 down) → clear error + retry
- Wrong SMS code 3x → rate limit lockout for 15min
- SMS code expiry after 5min → expired message + resend
- Concurrent SMS requests (spam tap) → debounce, only one sent
- Wrong password 5x → account lockout for 30min
- Access token expired mid-request → auto-refresh via interceptor
- Refresh token expired → force re-login screen
- Multiple devices same account → second device login OK
- JWT refresh race condition (concurrent requests trigger refresh simultaneously)
- API version check: old client → 426 Upgrade Required
- API version header missing → permissive pass-through
- New user auto-creation on first SMS verify
- Password login for user without password → guide to SMS

### Onboarding
- Name/birthdate → Hive local only (no server upload before PIPL)
- PIPL consent → triggers server upload of name/birthdate
- PIPL decline → app works locally, no sync, limited features prompt
- Empty name → validation error
- Future birthdate → validation error
- Child > 3 years → stage 5 recommendation
- App reinstall → login → restore data from server

### Scene Coaching
- Phrase card swipe between phrases
- Last card → loop or stop behavior
- Difficulty switching with unlock conditions (80%+ mastery)
- Locked difficulty display + unlock hint
- TTS play from asset (offline OK)
- TTS play failure → fallback text display
- Reaction buttons create InteractionEvent in Hive
- "spoken" reaction → mastery increment + particle animation
- "babbled" first time → Celebration Screen trigger
- "fussy" → comfort phrase switch

### AI Ask Coach
- Empty input → validation error, no API call
- Input > 500 chars → truncation warning
- Backend input validation (profanity/injection detection) [→EVAL]
- Backend output filtering (parenting methodology compliance) [→EVAL]
- LLM prompt injection attempt → blocked [→EVAL]
- SSE streaming display of LLM response
- ASR → text → LLM → response → TTS full E2E flow [→E2E]
- ASR confidence < 70% → automatic fallback to text input
- Rate limit: 10th request succeeds, 11th shows limit message
- TTS generation timeout (>5s) → show text-only result
- TTS cache hit → return cached audio (same phrase)
- Network offline → "needs internet" + guide to preset phrases
- LLM timeout (>10s) → error + retry (no daily count deduction)

### Progress Screen
- StageRing percentage calculation accuracy
- Per-scene mastery bar calculation
- Milestone timeline ordering (newest first)
- "本周数据" calculation (phrases this week, consecutive days)
- Empty state (new user, no data)  → encouraging message

### Celebration Screen
- First babble → full-screen animation
- Non-first babble → subtle "又进步了" feedback
- Share link generation → landing page URL
- "Not right? Cancel" → undo babble record
- Share failure → "saved to album" message

### Event Sync
- Online: batch upload events → server ingestion + progress recalc
- 1000+ events queued → chunked upload
- Upload failure → retain local, retry next time
- Duplicate upload (network retry) → server idempotent (UUID dedup)
- GET progress → update local Hive
- Network failure on progress fetch → use local data

### Analytics
- Screen view events logged on navigation
- Session start/end tracked (app lifecycle)
- Feature usage events (Ask Coach, TTS play, reactions)
- Events merged with interaction events for batch upload

### Push Notifications
- Daily 6pm local push
- Tap notification → open app → Smart Home
- Notification permission denied → silent fail

## Critical E2E Paths
1. First-time user complete journey: open → onboarding → login → PIPL → home → scene → TTS → reaction → progress update
2. First babble: reaction "babbled" → celebration screen → share
3. Daily use: open → home → scene → phrases → reactions
4. Ask Coach full chain: text input → LLM → SSE stream → TTS → play

## Eval Tests
1. Input profanity filter: test against list of inappropriate inputs
2. Output parenting compliance: test LLM responses against methodology principles
3. Prompt injection defense: test against known injection patterns

## Edge Cases
- App killed during event sync → events preserved in Hive
- Clock manipulation (device time changed) → server timestamps authoritative
- Very slow network (3G) → streaming display still works, just slower
- Two quick taps on reaction button → only one event recorded (debounce)
