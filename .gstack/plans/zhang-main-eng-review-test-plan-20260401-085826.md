## Affected Pages/Routes

- `/onboarding` — 3-screen flow: name entry, birthdate picker, scene preview. Validate edge cases: empty name, future date, age > 36 months, birthdate = today.
- `/home` (Smart Home) — Recommendation engine. Test time-of-day mapping (6 time slots), stage-aware scene filtering (5 stages), roadmap activity merge, "all mastered" congratulations state, empty scene at current difficulty.
- `/coaching/:scene` — Phrase card + adaptive state machine. Test all 10 state transitions (calm/fussy/crying/done x 4 reactions), audio playback (cached/fetch/error), reaction logging to sqflite, first babble celebration trigger.
- `/progress` — Dashboard. Test weekly stats query, streak calculation, per-scene mastery breakdown, difficulty progress bars, roadmap stage progress %, zero-interaction empty state, stage advancement celebration.
- `/roadmap` — Immersion roadmap. Test stage display, activity list per stage, activity completion, stage progress calculation, auto-advance on age change, manual override.
- `/celebration` — First Word screen. Test trigger on first babble, card generation with child name/phrase/date, share (plain URL), offline share fallback (save locally), "Not quite yet" dismiss + flag reset, replay from Milestones.
- `/journey` — Voice memo tab (native-only). Test hidden on web with "download app" message, recording flow, 30-second auto-stop, storage full warning.

## Key Interactions to Verify

- Tap reaction button during coaching → state transition + InteractionEvent created on `/coaching`
- Baby goes from calm to crying → phrase cards switch to comfort mode instantly on `/coaching`
- First ever "babbled" reaction → celebration screen triggers from `/coaching`
- Complete 3 "I said it" taps on a phrase → phrase marked as mastered, reflected in Smart Home recommendations
- Open app after 6pm → in-app banner with daily phrase on `/home`
- Stage auto-advancement when child ages past stage boundary on `/roadmap`
- Audio tap → fetch from OSS → cache → play. Second tap → play from cache on `/coaching`

## Edge Cases

- All phrases in all scenes mastered → congratulations state on `/home`
- Scene with no phrases at current difficulty → "coming soon" card on `/home`
- Child age > 36 months → Stage 5 stays active permanently on `/roadmap`
- Celebration dismissed accidentally → re-triggerable from Milestones tab on `/progress`
- No internet → phrase cards display (text only), audio unavailable indicator on `/coaching`
- Audio fetch failure → graceful degradation (text-only mode) on `/coaching`
- Concurrent audio play requests → previous audio stops, new audio plays on `/coaching`
- Empty name in onboarding → validation error on `/onboarding`
- Future birthdate in onboarding → validation error on `/onboarding`
- Clear app data → clean restart through onboarding

## Critical Paths (E2E)

- First-time user: Onboarding → Smart Home → first scene → tap reaction → see "1 phrase spoken!" counter → close → reopen → progress persisted
- Daily coaching session: Open → scene → 3 phrases with reactions → session summary → progress updated
- Fussy baby mid-session: Coaching → "smiled" → "smiled" → "fussy" → state transitions to gentler phrases → "calm" → resume normal
- Crying baby: Coaching → "fussy" → "crying" → comfort phrases → Chinese fallback offered → "done" → summary
- Milestone: Coaching → "babbled" (first ever) → celebration screen → share link → dismiss → viewable in Milestones
- Roadmap progression: View roadmap → complete activity → progress % updates → child ages → stage advances → new scenes unlock
- Offline mode: Disconnect network → open app → phrase cards visible → audio shows unavailable → tap reaction → event queued → reconnect → events sync
- Stage advancement: Child birthdate crosses stage boundary → auto-advance → new scenes appear in Smart Home → celebration
