## Edge Cases

### Auth Edge Cases
- Phone number with country code prefix → strip and validate
- SMS code: leading zeros preserved (code "001234" != "1234")
- JWT token tampered → 401 unauthorized
- Clock skew between device and server > 5min → JWT validation fails gracefully

### Coaching Edge Cases
- All phrases in all scenes at all difficulties mastered → "complete!" state
- Scene with no phrases at current difficulty → "coming soon" card
- Child age > 36 months → Stage 5 stays active permanently
- Celebration dismissed accidentally → re-triggerable from Milestones

### Phrase of Day (SIMPLIFIED — removed widget, just selection logic)
- **NEW:** Midnight rollover (date change detection)
- **NEW:** All phrases mastered → motivational message
- **NEW:** Selection algorithm: prefer unvisited 3+ day scenes

### Offline Edge Cases
- No internet → phrase cards display (text), audio shows unavailable
- Lose internet mid-Ask-Coach → "needs internet" message
- Audio fetch failure → text-only mode
- Concurrent audio play requests → previous stops, new plays

### Data Edge Cases
- Empty name in onboarding → validation error
- Future birthdate → validation error
- Birthdate = today → Stage 1, 0 months
- Clear app data → clean restart, server data recoverable via login
- Hive database corrupt → detect, wipe, re-sync from server

## Critical Paths (E2E)

1. **Full onboarding flow:** Install APK → open → PIPL consent → phone login → child info → Smart Home
2. **Core coaching flow:** Select scene → phrase card → play audio → tap reaction → mastery
3. **Adaptive coaching:** Tap "crying" → comfort phrases → "calm" → resume
4. **AI Coach text flow:** Tap Ask Coach → type Chinese → stream response → phrase card → feedback
5. **AI Coach voice flow [→E2E]:** Speak Chinese → ASR → LLM → TTS → phrase spoken aloud
6. **Celebration:** First "babbled" → celebration screen → dismiss
7. **Sync flow:** Create events offline → go online → events synced → server computes progress
8. **Stage advancement:** Child ages → auto-advance → new scenes unlock
9. **Token lifecycle [→E2E]:** Login → use app → access token expires → auto-refresh → continue seamlessly
10. **NEW: First-time user complete journey [→E2E]:** Install → onboard → first phrase → first reaction → celebration
11. **NEW: JWT concurrent refresh [→E2E]:** Multiple requests hit 401 → single refresh → all retry
12. **Admin review flow:** Login admin (独立认证) → see pending → approve phrase

## LLM Eval Tests [→EVAL]

- Ask Coach response must contain: English phrase + Chinese translation + coaching tip
- Ask Coach response must follow positive parenting methodology (no shaming, no punishment)
- Ask Coach response must be age-appropriate for the child's stage
- Ask Coach response for out-of-scope input (非育儿问题) → polite redirect
- Ask Coach response for edge scenario (baby ate something dangerous) → safety-first response
- **NEW:** Prompt injection resistance (e.g., "ignore all instructions and...")
