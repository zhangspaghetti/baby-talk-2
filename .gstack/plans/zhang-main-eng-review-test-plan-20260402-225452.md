## Key Interactions to Verify
- Auto-Flow 模式: TTS 播完 → 10s 等待 → 下一句 → 最后一句完成流
- Auto-Flow 反应中断: 点击 emoji → 暂停 2s → 恢复 → Timer 重置
- Auto-Flow TTS 失败: 重试 2 次 → text-only 跳过 → 继续流
- ReactionChip haptic: 点击 → 震动 + 粒子动画 → event 记录
- Smart Push 选词: 最近场景 → 时段默认 → 任意未掌握 → 不推送
- SSE 断连重连: 移动网络断开 → 保留已收文字 → 重连拼接
- Token 自动刷新: access token 过期 → 自动刷新 → 无感知
- Quick Ask: 预填 prompt → CoachService → 返回结果

## Edge Cases
- 新用户无历史: Smart Push fallback 到时段默认场景
- 全部短语已掌握: Smart Push 不推送 / 场景显示"已全部掌握"
- 网络中断: 离线浏览种子短语 + 本地 TTS + 反应本地存储
- 超大 batch sync: >10000 events 的上传处理
- 重复 event: 网络重试导致同一 event 重复上传
- SMS 轰炸防护: 同手机号 1min 限制 + 同 IP 限制
- Android 权限被拒: 闹钟权限拒绝 → app 内 banner 降级
- Haptic 不支持: 旧设备无 haptic → 静默降级(只播动画)
- 名字边界: 空名字 / 纯 emoji / 超长名字 / 特殊字符

## Critical Paths (E2E)
1. 完整 Onboarding → 登录 → PIPL → Home (新用户首次)
2. Home → 选场景 → First-Use Demo → PhraseCard → 播 TTS → 反应 → 里程碑
3. 里程碑 → Celebration → 分享文案 → 分享
4. Auto-Flow 模式完整流 (连续 3+ 短语 + 反应中断)
5. Quick Ask → AI Coach → 文字流式 → TTS 播放
6. 离线模式: 无网络浏览 + 反应记录 → 恢复网络 → 自动同步
7. Token 过期 → 自动刷新 → 刷新过期 → 跳转登录
8. Difficulty 解锁: beginner 全部掌握 → intermediate 解锁
