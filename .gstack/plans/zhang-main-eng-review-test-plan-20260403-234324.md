## Affected Pages/Routes

### Backend API
- `POST /api/v1/auth/sms` — SMS 发送限流 (手机号1min + IP 20/h + Redis 降级)
- `POST /api/v1/auth/verify` — 验证码校验 + 5次错误锁定 + JWT 生成
- `POST /api/v1/auth/login` — 密码登录 + 账号不存在处理
- `POST /api/v1/auth/refresh` — Token 刷新 + 过期/吊销处理
- `POST /api/v1/sync/events` — 批量 event 上传 (@Transactional 回滚 + 幂等性)
- `GET /api/v1/sync/progress` — 聚合 progress 返回 (新用户空状态)
- `POST /api/v1/coach/ask` — RAG → LLM → SSE 流式 (速率限制 + 输入输出过滤 + pgvector 降级 + Last-Event-Id)
- `GET /api/v1/config/version` — API 版本检查 (426 + 无头 → 400)
- `GET /actuator/health` — 健康检查端点

## Key Interactions to Verify
- Onboarding 完整流程 (5步)
- Scene 练习: 打开场景 → TTS播放 → 说短语 → 记录反应 → 进度更新
- Auto-Flow: TTS连续播放 → 10s间隔 → 暂停/继续 → TTS失败跳过
- AI Coach: 文字输入 → SSE流式显示 → TTS生成 → 播放
- 里程碑: babble reaction → milestone检测(幂等) → 庆祝屏 → 分享
- 离线→在线: 离线记录events → 恢复网络 → 自动同步 → 进度一致
- 推送: 6pm每日 + Smart Push选词 + 8pm Bedtime Summary

## Edge Cases
- SMS: 5次错误验证码 → 30min锁定
- API: 无X-App-Version头 → 400 Bad Request
- Redis 宕机: 限流内存fallback + SMS拒绝发送 + TTS跳过缓存
- SSE 断连: 重连3次 + Last-Event-Id + 部分文字保留
- Auto-Flow TTS 失败: 重试2次 → text-only跳过
- pgvector 查询失败: 降级LLM-only模式
- Milestone 重复触发: UNIQUE约束拦截 (并发/重试)
- 空状态: 新用户所有屏幕 (Progress/Home/Discovery)
- 通知权限被拒: 降级为app内banner
- Android 12/13 闹钟权限差异

## Critical Paths
- 新用户首次完整旅程: 安装 → Onboarding → 首页 → 场景 → 说第一句
- Daily loop: 打开app → 推荐 → 练习 → 记录 → 关闭
- AI Coach: 输入 → RAG检索 → LLM → SSE → TTS
- Sync: 离线events → 上传(事务) → progress重算 → 里程碑检测(幂等)
- Auth: SMS → 验证 → JWT → 刷新 → 过期 → 重登录

## LLM Eval Requirements
- 10+ test cases covering: 正常育儿问题 / 注入尝试 / 非育儿话题 / 多语言
- 评分标准: safety (0/1), relevance (0-5), tone (0-5)
- CI pipeline: prompt/filter 变更自动触发
- 基线对比: regression 检测
