### API Endpoints
- `POST /auth/sms` — Send verification code
- `POST /auth/verify` — Verify SMS code, return JWT
- `POST /auth/login` — Username/password login
- `POST /auth/refresh` — Refresh token
- `POST /sync/events` — Batch upload interaction events
- `GET /sync/progress` — Get user progress
- `POST /sync/progress` — Update user progress
- `POST /coach/ask` — AI phrase request (text → RAG → LLM → response)
- `POST /coach/feedback` — Thumbs up/down on AI response
- `GET /coach/tts` — On-demand TTS audio generation
- `GET /admin/pending` — List pending phrase reviews
- `POST /admin/approve` — Approve phrase, add to knowledge base
- `POST /admin/discard` — Discard pending phrase

## Key Interactions to Verify

- Phrase card tap "I said it" correctly increments mastery count on Scene Coaching screen
- Reaction buttons (smiled/fussy/no_reaction/babbled) correctly update coaching state on Scene Coaching screen
- Baby state transitions (calm→fussy→crying→done) produce correct phrase set changes
- Phrase of Day widget rotates daily and prefers unvisited scenes on Smart Home
- Quiet nudge appears after 48h inactivity and respects dismiss frequency cap on Smart Home
- Couple mode shows extra-large text + countdown timer on Scene Coaching screen
- AI Ask Coach streams response and displays in phrase card format
- Rate limiting shows user-friendly message after 10 daily requests
- Audio playback works for bundled TTS files (offline)
- Progress screen shows accurate stats reflecting local + synced data

## Edge Cases

- All phrases mastered in a scene → graceful "completed" state, not empty screen
- All phrases mastered in all scenes → Phrase of Day shows motivational message
- Child birthdate in the future (typo) → validation error during onboarding
- First babble celebration tapped accidentally → dismiss + reset flag
- Network drops mid-sync → events queued locally, synced on reconnect
- SMS send fails → clear error message + retry button
- LLM timeout (>10s) → "Thinking trouble" retry prompt
- Audio file missing/corrupt → show text-only phrase card
- Recording permission denied → explanation dialog + settings link
- Recording too short (<1s) → prompt retry
- App backgrounded mid-coaching-session → resume on foreground
- Zero data state (new user, no interactions yet) → encouraging empty states on progress

## Critical Paths (E2E)

- **Onboarding flow:** Open app → phone login → enter child name + birthdate → see Smart Home with correct stage
- **Core coaching flow:** Select scene → see phrase card → play audio → tap reaction → next phrase → mastery increment
- **Adaptive coaching:** Tap "crying" reaction → app switches to comfort phrases → tap "calm" → resume
- **AI Coach flow:** Tap Ask Coach → type Chinese description → get English phrase + audio + tip → tap helpful
- **Celebration flow:** First "babbled" reaction → celebration screen → share or dismiss
- **Couple mode flow:** Toggle couple mode → countdown → large text → done → return to normal
- **Sync flow:** Create events offline → go online → events synced to server → verify server data
