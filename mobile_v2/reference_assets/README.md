# Reference Assets Quarantine

This directory may hold copied wording, audio, design samples, and other raw
reference material for Baby Talk vNext.

Reference assets are not product truth. Files here cannot be imported by
`mobile_v2/lib`, cannot define runtime behavior, and cannot feed vNext UI,
state, repository, or domain truth.

Any useful material copied from old sources must be re-derived behind the
Family English Micro-ritual semantic boundary before it can become runtime
code.
