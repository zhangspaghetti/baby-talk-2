# Baby Talk 2 Phase 1 UX 整改清单

基于 UX 汇总审查报告生成，按优先级排序。默认目标是：先把“现在说一句”的主路径做清晰，再补齐动态交互层的无障碍门槛。

## P0 本迭代必须完成

### 1. 收起所有工程态和调试态文案
- 范围：首页、练习页、账号/同步页、Mentor 面板
- 要求：正式 UI 不再出现 `idle`、`phase`、`code ready`、`route scope`、`append-only`、`local-only` 等内部状态词
- 验收：用户能只看到任务导向文案，如“已保存到本机”“恢复联网后自动同步”“今天还能再问 1 次”

### 2. 首页首屏只保留一个主 CTA
- 范围：首页
- 要求：首屏只保留 `继续今天这一句` 或 `开始今天这一句`
- 验收：首页 2 秒内能回答“我现在该做什么”，Mentor、同步、最近结果不与主 CTA 同级竞争

### 3. 建立动态状态播报层
- 范围：Mentor、C3 练习、离线 banner、播放/录音、失败与重连、完成反馈
- 要求：关键状态变化可被屏幕阅读器感知
- 验收：至少覆盖离线、重连中、重连失败、TTS 就绪、ASR 失败、已完成短语、速率限制

### 4. 修正弹层焦点管理
- 范围：Drawer、Bottom Sheet、Mentor 面板、发现页弹层
- 要求：定义初始焦点、焦点顺序、关闭后返回触发点
- 验收：外接键盘和屏幕阅读器用户不会在弹层中迷失

### 5. 给 Auto-Flow 和庆祝动画补可控性
- 范围：C3 激活框、场景完成动画、花园成长动画
- 要求：支持暂停、继续、减少动效模式
- 验收：系统开启减少动效时不再强制播放高动态动画

### 6. 修正 Mentor FAB 和建议/聊天切换语义
- 范围：全局 Mentor FAB、面板顶部切换器
- 要求：FAB 语义改为动作导向；切换器暴露选中态
- 验收：屏幕阅读器可读出“打开小禾老师面板”，并知道当前在“建议”还是“聊天”

## P1 下个迭代完成

### 7. 重构 4 个主导航的职责边界
- Home：继续今天这一句
- Discover：换场景/找下一句
- Garden：看长期成长
- Growth：看记录、里程碑、日记
- 验收：同一个 activity 不再在多个 tab 承担相同“继续练习”职责

### 8. 重排练习页首屏信息层级
- 要求：首屏只保留短语、中文义、播放、宝宝反应、下一步
- 验收：机制说明、同步说明、路线信息下沉到二级层

### 9. 拆分账号/同步页
- 一级：登录并同步
- 二级：共享协作
- 三级：撤回同意、删除账号等高风险设置
- 验收：高风险动作不再与主任务动作并列

### 10. 统一产品术语表
- 范围：场景、活动、短语、成长、同步、建议、第一句、最近一次练习
- 验收：不再混用内部命名、临时英文、用户文案

### 11. 完成对比度与系统大字号回归
- 范围：浅色/深色模式、花园状态色、标签、提示块、按钮
- 验收：完成 WCAG 2.1 AA 对比度检查，并验证 200% 缩放与大字号不破版

### 12. 补手动无障碍验证清单
- 范围：TalkBack、VoiceOver、外接键盘、高对比度、减少动效
- 验收：形成可复用回归脚本，并至少跑通 Home、练习、Mentor、Growth 四条路径

## P2 持续优化

### 13. 将 Mentor 从常驻入口升级为情境辅助层
- 条件触发：用户停留过久、重复播放、连续失败、重复切换场景
- 验收：Mentor 干扰减少，但求助效率更高

### 14. 强化 Growth 的反馈闭环
- 衍生指标：本周说了几次、最自然场景、宝宝最常见反应、连续天数
- 验收：成长页从记录容器变成持续练习的动力系统

### 15. 为花园拖动提供替代路径
- 要求：除拖动外，提供键盘/按钮式导航与操作方式
- 验收：运动障碍和辅助输入设备用户能完成主要花园操作

## 建议切片顺序

1. 首页降噪 + 工程态下沉
2. Mentor FAB 语义 + 面板焦点管理
3. 动态状态播报层
4. Auto-Flow/庆祝动画减少动效支持
5. 练习页首屏重排
6. 账号/同步页分层
7. 导航职责重构
8. 对比度与手动无障碍回归

## Definition of Done

- 主路径首屏只保留单一主任务
- 动态状态对屏幕阅读器可感知
- 所有弹层具备完整焦点管理
- 动效支持暂停或减少动效
- 术语统一，不再暴露内部状态词
- 已完成至少一轮手动无障碍回归
