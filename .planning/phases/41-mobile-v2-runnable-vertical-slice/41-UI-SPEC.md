## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, dense inline text/icon gaps |
| sm | 8px | Compact label/body spacing, chip inner gaps |
| md | 16px | Default element spacing and card internal groups |
| lg | 24px | Section padding and spacing between lens sections |
| xl | 32px | Major breaks between room header, content, and CTA group |
| 2xl | 48px | Empty/deferred state vertical breathing room |
| 3xl | 64px | Page-level spacing only; avoid in dense phone screens |

Exceptions: Touch targets are minimum 48x48px. Primary bottom CTA height is 56px. Audio/play affordance is minimum 56x56px and may grow to 72px when it is the main Room Support control. Page horizontal padding is 20px on normal phones and 16px on narrow phones. Existing old-mobile 12px/20px constants may be used only when re-derived as layout implementation details; the phase contract remains the 4/8/16/24/32/48/64 scale.

## Typography

Use exactly these 4 sizes and 2 weights in Phase 41 runtime UI: 400 regular and 600 semibold. Do not introduce score-like numeric hierarchy or oversized dashboard numerals.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.6 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 32px | 600 | 1.2 |

Typography rules:

- `Display` is reserved for `Shoes on.` only.
- Chinese helper copy uses Body or Heading, never Display.
- Optional variants `One shoe. Two shoes.` and `Tap tap.` use Body or Heading, visually secondary to `Shoes on.`.
- Labels are for lens names, state chips, and secondary CTA text only.
- Do not use negative letter spacing or viewport-scaled font sizes.

## Interaction Contract

Phase 41 is a single guided vertical slice over one persistent Ritual Room, not a tabbed app shell.

| Surface | Interaction |
|---------|-------------|
| First Entry | Single full-screen entry view. One primary CTA opens `shoes_on_room_v1`. No multi-step onboarding progress indicator. |
| Today Orientation | Shows the active room and current-moment orientation. CTA enters Room Support. If returning from support, copy changes to: `这个小声音已经在你们的出门 routine 里了。想先看看花园记忆吗？` |
| Room Support | Parent can read the fixed sound, optionally use a playback button, read action binding, and confirm they know how to say it. No recording, microphone, scoring, baby response requirement, or completion animation. |
| Memory Lens | Parent chooses exactly one low-pressure option. Selection may update a local visual placeholder or gentle response, but must not implement production Garden Memory transitions. |

Navigation:

- Use a simple route stack or in-memory lens state: First Entry -> Today Orientation -> Room Support -> Memory Lens.
- No bottom navigation, no drawer, no global mentor FAB, no multi-room switcher.
- Back navigation may return to the previous lens without erasing the room.
- All primary actions must be reachable with one thumb near the lower safe area.

Motion:

- Button press feedback may scale to 0.96 for 150ms ease-out and must respect reduced motion.
- Lens transitions use short 150-250ms fade/slide only.
- Do not add celebration animations, confetti, reward growth, or decorative floating blobs.

## Component Contract

Implement the smallest local component vocabulary needed for this phase:

| Component | Contract |
|-----------|----------|
| RitualRoomSurface | One warm surface card or unframed section for `出门小声音`, radius 16px, subtle warm shadow, no nested cards. |
| FixedSoundDisplay | Displays `Shoes on.` in Display size, #3B8577, centered only within the room surface, not as a flashcard deck. |
| ActionBindingHint | Shows the action binding and no-response reassurance as parent-facing body copy. |
| AudioPlayControl | Optional. Uses speaker/play icon only; semantics label `听 Shoes on. 怎么说`; no microphone or waveform. |
| MemoryOptionGroup | Three 48px-min touch options, visually equal weight; selected option uses one accent border and soft surface response. |
| GentleResponse | Optional local placeholder after Memory Lens selection; copy must be narrative and low-pressure, not a status transition proof. |

Surface rules:

- Prefer one primary room surface per lens. Do not build a dashboard of cards.
- Use icons sparingly: door/shoe/play/leaf-style memory icon are acceptable if rendered as simple Material line icons.
- No child-targeted cartoon classroom visuals, badges, rewards, streak marks, or grid of illustrated lessons.
