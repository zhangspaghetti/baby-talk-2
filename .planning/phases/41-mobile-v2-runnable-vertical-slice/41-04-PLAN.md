<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API-shaped request -> authority | Untrusted IDs, revisions, and raw events enter state transition logic. |
| pure module output -> commit | Derived output must be atomically accepted or discarded. |
| journal -> replay | Historical evidence must not become current decision authority. |

| T-41-04-03 | Information Disclosure | failed pipeline | mitigate | No partial commit and raw-sentinel runtime audit. |
