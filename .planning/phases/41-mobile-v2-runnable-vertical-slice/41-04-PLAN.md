## 2026-06-19 Interaction Engine Override

This plan is controlled by `41-INTERACTION-ENGINE-CONTRACT.md`. Room Support is
not a static talk sheet as a terminal product and not a child-performance
reaction session.

Plan 04 must render:

- stable Ritual identity and anchor
- one snapshot-owned current utterance as the primary output focus
- default action-bound language as support, not progression
- neutral inline context choices plus additional choices in a bottom sheet
- context submitting/retry feedback without leaving the screen
- in-place revised utterance and context label
- no microphone, text field, signal control, or strategy tray in this Phase 41
  projection, while those channels remain executable in the engine

Do not implement navigation to a separate reaction page. Do not use reaction
choices to record compliance, correctness, learning, or performance.

### 2026-06-17 Historical Product Correction

This plan must follow `41-SCHEMATIC-DESIGN.md`. Room Support is not a one-phrase confirmation screen and not a child reaction session.

The approved D.4.5 prototype at
`assets/prototypes/phase41-d4-5-interaction-engine.png` controls presentation.
D.4.3 remains historical visual grounding only:

- compact parent-child illustration plus `Shoes on.` identity header
- response-owned context label and helper, with no header intro paragraph
- header limited to about 22-26% of the viewport
- one current complete caregiver utterance occupying most of the body
- one snapshot-owned action / TPR timing cue
- one `听一遍` play/pause control
- text-only reaction choices inline plus a half-height additional-choice sheet
- last usable utterance preserved during inline submitting state
- response-owned reassurance and quiet exit `先这样就好`

Stable room values must be read from `RitualRoomContent`; current context and
utterance values must be read from `RitualInteractionSnapshot`. Widgets must
not import DTOs, mock sources, or fixtures. The music-list screenshot is a
hierarchy reference only; do not copy social metrics, album artwork, dark
styling, or playlist semantics.

After the visual gate is approved, the widget geometry, illustration treatment,
and playback hierarchy must follow the prototype linked from
`41-SCHEMATIC-DESIGN.md` and the approved static asset at
`mobile_v2/assets/illustrations/rituals/shoes_on/shoes_on_approved_v1.png`.
Stop execution if the gate remains pending or either approval artifact is
missing.

Do not implement child-performance reaction chips, `下一句`, lesson progression,
completion, `我知道怎么说了`, or `看看这个声音怎么留在家里` as Phase 41 core
actions. Neutral context chips are required by the Interaction Engine slice.
Memory Lens remains optional after exit and must not become full memory tracking.
