## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, verifier/copy badges, compact inline separations |
| sm | 8px | Compact element spacing, chip internal rhythm |
| md | 16px | Default element spacing, confirmation prompt padding |
| lg | 24px | Section padding, Garden Memory state groups |
| xl | 32px | Layout gaps, empty-state spacing |
| 2xl | 48px | Major section breaks and minimum touch target height |
| 3xl | 64px | Page-level spacing only |

Exceptions: existing Flutter constants include 12px and 20px (`spacingSm`, `spacingLg`) and may remain when reusing current app widgets. Do not introduce 2px spacing in Phase 40 UI work except inherited progress-segment internals; Phase 40 should not add progress bars.

Interaction sizing:

| Item | Required Size |
|------|---------------|
| Parent confirmation buttons | 48px minimum height; prefer 56px for the primary action |
| Icon-only controls | 48x48px minimum touch target |
| Bottom sheets/modals | 24px top/body section padding; 16px between controls |
| State chips | 32px minimum height; 8px horizontal internal gap |

## Typography

Phase 40 new UI surfaces may use exactly two weights: regular 400 and semibold 600. Existing app-level styles that use 500/700 are reference material, but new Activation Governor / Garden Memory surfaces should not introduce extra weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.6 |
| Label | 13px | 600 | 1.4 |
| Heading | 20px | 600 | 1.3 |
| Display | 28px | 600 | 1.2 |

Usage rules:

- Body copy explains pacing and confirmation in plain parent-facing Chinese.
- Labels name states such as `candidate`, `active`, `familiar`, `resting`, `expandable`, and `belongs_to_family` only in internal/debug/proof surfaces; parent-facing surfaces use natural Chinese wording.
- Display text is reserved for the spoken English sound itself, not for progress, counts, or achievement language.
- Do not use large type for numbers, capacity, streaks, scores, checklist totals, or verifier counts in parent-facing UI.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFF8F0 | App/page background, quiet Warm Paper base |
| Secondary (30%) | #FFFFFF | Cards, confirmation surfaces, Garden Memory state containers |
| Accent (10%) | #FF8C42 | One primary parent action per surface, selected state after explicit parent intent, Governor-approved activation affordance only |
| Destructive | #D94B3C | System failure or truly destructive admin/developer action only; not for parent performance or child response |

Accent reserved for: `Confirm this sound`, Governor-approved activation CTA after parent intent/readiness, selected confirmation choice, focused input border, single primary bottom action. Never use accent for completion percentage, streak, reward, unlock, progress fill, score, or “more active rituals” goals.

Supporting semantic colors:

| Token | Value | Usage |
|-------|-------|-------|
| English | #3B8577 | Spoken English fixedSound/example text only |
| Info | #3B8577 | Mentor/Governor explanation and open Explore guidance |
| Success | #6B8F5E | Parent-confirmed familiar/belongs-to-family acknowledgement, with no reward framing |
| Warning | #E6A817 | Pacing caution, defer/rest suggestion, save-for-later notice |
| Muted text | #8A7D76 | Resting/deferred state explanations |

State presentation contract:

| State / Decision | Visual Treatment |
|---|---|
| `candidate` | Neutral secondary surface, muted label, no accent CTA that implies action today |
| `active` | Accent may appear only when Activation Governor produced `allow_activation` and parent intent/readiness is present |
| `familiar` | Soft success treatment after parent confirmation; no progress meter |
| `resting` | Muted/warning-soft treatment, explicitly non-punitive |
| `expandable` | Info/English-soft treatment for nearby option; must not look like an unlock/reward |
| `belongs_to_family` | Warm success acknowledgement after explicit parent confirmation; no celebration confetti or achievement badge |
| `nearby_expansion_only` | Info-soft cue; secondary action unless parent is explicitly choosing to try it now |
| `defer_to_garden` | Warning-soft or neutral Garden review cue; never framed as failure |
| `save_for_later` | Neutral saved state; must not silently become active |
| `rest_existing` | Rest suggestion plus parent confirmation; no inactivity penalty visuals |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 确认这个声音 |
| Empty state heading | 还没有需要确认的家庭声音 |
| Empty state body | 先在日常里轻轻试一句。小禾会等你觉得自然了，再请你确认。 |
| Error state | 暂时没法保存这次确认。请稍后再试；刚才的选择不会被当作完成记录。 |
| Destructive confirmation | none — Phase 40 must not introduce delete/reset/destructive parent actions |

Parent-confirmation prompts that are allowed:

| Transition | Prompt | Primary Action | Secondary Action |
|---|---|---|---|
| `active -> familiar` | 这句最近会自然冒出来吗？ | 确认这个声音 | 还不急 |
| `active -> resting` | 要不要先放一边？ | 先放一边 | 继续留着 |
| `familiar -> belongs_to_family` | 这句是不是已经属于你们家了？ | 记到家里 | 再看看 |
| weak-signal review prompt | 要不要看看这句现在适不适合？ | 看看这句 | 稍后再说 |

Activation copy rules:

- Explore copy may say: `看看这个说法`, `了解这个场景`, `以后也可以试试类似的声音`, `这里有几个例子`.
- Activate copy may only appear with parent intent/readiness plus Governor decision. Acceptable governed examples: `今天就把这句放进你们家的日常`, `加入家里的声音`, `现在试这一句`.
- Banned without Governor decision: `今天试试这个`, `加一个新声音`, `开始这个 micro-ritual`, `睡前就说这句`, `已为你加入日常`, `自动变熟悉`, `连续完成`, `解锁`, `成长`, `打卡`, `streak`, `完成度`, `得分`.
- Runtime copy must say it is using an existing pacing decision, not deciding activation policy itself.
- Garden copy must ask and reflect parent confirmation; it must not claim family transfer from telemetry, repeated opens, child response, elapsed time, or usage count.

## Phase 40 Interaction Contract

Phase 40 does not lock final UI layout, navigation, route names, component names, database schema, API payloads, event names, Runtime Agent payloads, or activation algorithms. It does lock the interaction meaning below for any UI or proof fixture created now or later.

| Interaction Surface | Contract |
|---|---|
| Explore | Open by default. Can show candidates, examples, routes, and explanations without Governor approval when it does not ask for action now. |
| Activate | Any CTA or implication that a candidate should enter family routine now must require parent intent/readiness plus Activation Governor decision. |
| Home / Onboarding | Can orient the current moment and show candidates; any first-ritual or today/now action must be governed. |
| Runtime | May consume an existing Governor decision. Must not show UI/copy implying Runtime decided activation policy. |
| Garden Memory | Presents state and collects low-pressure confirmation. Must not own activation policy or infer meaningful transfer from weak signals. |
| Reminder / Push-like copy | Any copy that says or implies “say this now/today” is activation intent and must be governed. |
| Weak-signal prompt | May ask the parent whether to review, rest, or confirm. Must not persist `familiar`, `resting`, `belongs_to_family`, or `active` by itself. |

Required non-pressure behaviors:

- No checklist UI for Garden Memory states.
- No streaks, score, completion rings, unlock states, reward badges, fertilizer/growth/flower-stage progress, or punishment/inactivity visuals.
- No “capacity” goal shown to parents. The default active capacity of 3 and upper bound of 5 are internal protection parameters only.
- No child-response requirement. Parent confirmation is about family routine fit, not child performance.
- Resting must read as a normal pacing choice, not a failure.
