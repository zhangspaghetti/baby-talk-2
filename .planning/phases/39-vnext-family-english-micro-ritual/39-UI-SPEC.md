# Phase 39 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none; Flutter `ThemeExtension` + `DESIGN.md` manual contract |
| Preset | not applicable |
| Component library | Flutter Material 3 plus re-derived Baby Talk widgets (`AppSurfaceCard`, `AppAudioButton`, `AppScaleButton`, `AppEmptyState`, `AppBanner`, `AppEnglishPhrase`) |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tiny inline padding, pressed-state optical adjustments |
| sm | 8px | Compact element spacing, label/body separation, chip internals |
| md | 16px | Default element spacing, card inner grouping, sheet content rhythm |
| lg | 24px | Section padding, card vertical padding, between major controls |
| xl | 32px | Empty-state spacing, first-screen vertical rhythm |
| 2xl | 48px | Major section breaks, bottom breathing room above safe area |
| 3xl | 64px | Page-level spacing only when a surface has very little content |

Exceptions: keep minimum touch targets at 48x48px; primary bottom action height at 56px; pronunciation/play button target at 56x56px minimum; phone content width max 430px. Existing 20px horizontal padding from `AppLayoutConstants.horizontalPadding` is allowed because it is already established and remains a multiple of 4. Do not introduce 2px spacing tokens in `mobile_v2` surfaces for this phase.

## Typography

Use exactly these four sizes and two weights in `mobile_v2` UI surfaces for this phase. Existing old-app 500/700 weights should map to semibold in re-derived widgets.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px | 400 | 1.6 |
| Label | 13px | 400 | 1.5 |
| Heading | 20px | 600 | 1.3 |
| Display | 32px | 600 | 1.2 |

Display is reserved for the stable English sound / micro-ritual line only, in Fraunces and `#3B8577`. Do not use display typography for activity names, progress claims, scores, streaks, or celebratory completion language.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8F0` | App background, full-screen warm paper base |
| Secondary (30%) | `#FFFCF7` | Cards, sheets, quiet surface blocks; avoid pure white in new `mobile_v2` UI |
| Accent (10%) | `#FF8C42` | Primary CTA, one selected choice per screen, focused input border, Mentor/Xiaohe primary affordance |
| English functional | `#3B8577` | Stable English sound text, pronunciation-related emphasis, tiny info hints only |
| Destructive | `#B36B5E` | Destructive actions only; no destructive user actions are in scope for Phase 39 |

Accent reserved for: primary CTA, selected onboarding/current-moment choice, focused field border, one Xiaohe primary affordance. Accent must not be used for counts, progress, streaks, badges, Garden state, or decorative gradients.

Semantic notes: use `#6B5E57` for secondary copy, `#8A7D76` for muted helper copy, `#D4E8E3` only as a soft pronunciation/English background, and warm error copy that describes system failure without implying the parent did something wrong.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 开始小仪式 |
| Empty state heading | 还没有加入你家的英语声音 |
| Empty state body | 先从一个每天都会发生的小动作开始，小禾会帮你挑一句可以轻轻说出口的声音。 |
| Error state | 小禾暂时没有准备好。先用这个常见小仪式，等网络恢复后再换得更贴近现在。 |
| Destructive confirmation | none; Phase 39 must not introduce destructive user actions |

Copy rules: address the parent, not the child. Use low-pressure verbs: `试试`, `轻轻说`, `先放着`, `今天到这里`. Do not use `完成`, `打卡`, `连续`, `解锁`, `挑战`, `评分`, `正确率`, `宝宝学会了`, `AI生成`, `模型`, `置信度`, `重新生成`, or `prompt` in parent-facing UI.

## Surface Interaction Contract

| Surface | Required Contract | Forbidden Contract |
|---------|-------------------|--------------------|
| Onboarding | First screen leads to one candidate Family English Micro-ritual through a warm, low-pressure current-routine choice; it should collect only what is needed for parent comfort/readiness. | Do not make onboarding an activity/path picker, fixed phrase-set lesson, required profile form, or `starterPhraseId` seed. |
| Home | Orient the current family moment and one gentle micro-ritual possibility; keep the page useful even when interpretation is uncertain. | Do not show next incomplete activity, phrase card list, task dashboard, completion prompt, streak, or content-maximizing recommendation. |
| Practice | Help one micro-ritual become speakable in the routine: stable English sound, Chinese meaning/support, pronunciation playback, and a low-pressure `我说了` style confirmation. | Do not require child response, count phrase completion, advance through a phrase list, record pronunciation score, or imply failure. |
| Garden | Phase 39 only shows a quiet non-scoring memory boundary/placeholder: family language can be remembered later when parents confirm it belongs. | Do not show growth stages, fertilizer, blooming, streak, completion-derived progress, unlocks, or Garden Memory state-transition controls. |

Interaction states required: loading must keep a local/default option visible; empty state must offer a first micro-ritual path; error state must offer a non-blocking fallback; offline/unknown context must not blank the page; reduced-motion must be respected for pressed-scale and panel transitions.

## Component Contract

| Component Pattern | Use | Constraint |
|-------------------|-----|------------|
| Warm surface card | Candidate ritual, moment explanation, non-scoring memory placeholder | `#FFFCF7`, 16px radius, warm shadow only when elevated; no nested card stacks. |
| Pronunciation control | Play the stable sound / standard pronunciation | Speaker/play icon only, 56px target minimum, no microphone, waveform, recording permission, or scoring affordance. |
| Primary bottom action | First ritual start / parent said it | 56px height, scarce orange, one per screen. |
| Choice chips / routine choices | Parent selects current routine or comfort signal | 48px target minimum, selected state may use accent border/soft fill, never badges or progress chips. |
| Banner | Offline, system error, low-confidence context | Warm soft background, problem + next step, no blame language. |
| Placeholder memory surface | Garden boundary in Phase 39 | One quiet line or small sprout-like visual is allowed; no state mechanics until Phase 40. |
