| Boundary | Description |
|---|---|
| `mobile_v2/lib` source -> vNext product truth | Runtime/product code is trusted by future UI and state layers, so old semantic imports and terms must fail. |
| Old `mobile/` imports -> `mobile_v2` | Old complete app code is tempting to copy and can carry deprecated product meaning. |
| Reference/quarantine assets -> runtime code | Allowlisted old material must not become state, repository, UI, or domain truth. |
