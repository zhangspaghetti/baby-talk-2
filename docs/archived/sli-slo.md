# SLI/SLO 文档

## 概述

本文档定义 BabyTalk 关键链路的 SLI（Service Level Indicator）和 SLO（Service Level Objective）。

## SLI 定义

| 链路 | SLI | 计算方式 |
|---|---|---|
| API 可用性 | 成功请求比例 | 2xx 响应 / 总请求 |
| API 延迟 | P50/P95/P99 延迟 | 百分位数计算 |
| 练习上报成功率 | 上报成功比例 | 成功上报 / 总上报 |
| 知识库检索准确率 | 相关结果比例 | 相关结果 / 总返回结果 |
| Mentor 响应时间 | 首 token 延迟 | 请求到首 token 时间 |

## SLO 目标

### API 可用性

| 指标 | 目标 | 测量窗口 |
|---|---|---|
| 可用性 | 99.9% | 30 天 |
| 错误率 | <0.1% | 5 分钟 |

### API 延迟

| 端点 | P50 | P95 | P99 |
|---|---|---|---|
| 登录 | <100ms | <200ms | <500ms |
| 练习上报 | <200ms | <500ms | <1s |
| 知识库检索 | <150ms | <300ms | <500ms |
| Mentor 对话 | <500ms | <1s | <2s |
| 家庭组状态 | <100ms | <200ms | <500ms |

### 练习上报

| 指标 | 目标 | 测量窗口 |
|---|---|---|
| 上报成功率 | 99.5% | 1 小时 |
| 去重准确率 | 99.9% | 1 天 |

### 知识库检索

| 指标 | 目标 | 测量窗口 |
|---|---|---|
| 检索准确率 | >90% | 1 天 |
| 检索延迟 P95 | <300ms | 5 分钟 |

### Mentor 对话

| 指标 | 目标 | 测量窗口 |
|---|---|---|
| 首 token 延迟 P95 | <1s | 5 分钟 |
| 完整响应延迟 P95 | <3s | 5 分钟 |
| Fallback 使用率 | <5% | 1 小时 |

## 告警规则

| 告警 | 条件 | 严重级别 | 通知方式 |
|---|---|---|---|
| API 可用性下降 | <99.5% 持续 5min | P1 | PagerDuty + Slack |
| API 延迟升高 | P95 >2x SLO 持续 5min | P2 | Slack |
| 练习上报失败 | >1% 持续 10min | P2 | Slack |
| 知识库检索超时 | P95 >500ms 持续 5min | P2 | Slack |
| Mentor Fallback | >10% 持续 10min | P3 | Slack |
| 磁盘使用率 | >80% | P2 | Slack |
| 内存使用率 | >90% | P1 | PagerDuty |

## 仪表盘

### 核心指标仪表盘

- API 请求量 (QPS)
- API 延迟分布 (P50/P95/P99)
- 错误率 (4xx/5xx)
- 活跃用户数

### 练习链路仪表盘

- 上报 QPS
- 上报成功率
- 去重命中率
- 延迟分布

### 知识库仪表盘

- 检索 QPS
- 检索延迟
- 缓存命中率
- 索引大小

### Mentor 仪表盘

- 对话 QPS
- 首 token 延迟
- Fallback 使用率
- 模型调用延迟
