# Flutter Mobile Onboarding V21 交互结论

日期：2026-05-28
状态：Onboarding V21 子设计已最终确认（基于 V20 迭代，含 UX 优化、微交互规范、专业转场动画）
前序版本：2026-05-26-flutter-mobile-onboarding-design.md (V20)

## 1. 背景与目标

V20 确认了"小禾老师一句式引导 + 单手快速路径"的大方向，本轮在 V20 基础上迭代交互细节。

V21 调整目标：

1. 场景选择从 2×3 网格改为大按钮纵向列表，降低误触和决策成本。
2. 练习页去掉句卡边框，让英文直接浮在页面上，减少"需要先读完卡片"的心理负担。
3. 发音播放从独立按钮弱化为小图标，不与主 CTA 竞争视觉权重。
4. 宝宝反应增加图标 + 延长自动跳转时间，降低分心场景下的操作成本。
5. 结束态增加视觉记忆点（种子萌芽动画）和动态文案系统，让完成感更具体。
6. 练习页小禾气泡保留但改为场景动态文案，增强陪伴感。

非目标不变：

- 不恢复长聊天式 onboarding。
- 不把第一句练习做成小课程或多步骤打卡。
- 不在 onboarding 中展示拼音或英文转写。
- 不在年龄选择后推断宝宝偏好、性格或能力。

## 2. 场景选择

从 2×3 网格改为大按钮纵向列表。

页面结构：

1. 顶部显示"小禾老师 / 一句就好"。
2. 小禾老师一句气泡：`选现在的场景就好。`
3. 主标题：`今天先说一句`
4. 一行提示：`选个正在发生的场景`
5. 场景按钮：纵向列表，每行一个，≥48px 高
   - 喂饭
   - 喝水
   - 换尿布
   - 洗澡
   - 睡前
   - 出门
6. 年龄作为后置入口：`宝宝多大？可稍后补`
7. 底部主按钮：`开始一句`
8. 顶部次要动作：`直接给一句`

默认选中逻辑：

- 首次打开：根据当前时段推断最可能场景（7-9 点→喂饭，10-11 点→喝水，12-14 点→换尿布，15-17 点→洗澡，18-21 点→睡前，其他→出门）。
- 非首次打开：默认选中上次使用的场景。

设计要求：

- 场景按钮使用纵向列表布局，不使用 2×3 网格。
- 选中态使用 --accent (#FF8C42) + --text-on-accent (#FFFFFF)。
- 未选中态使用暖纸表面 + 细边框。
- 场景选择是首屏主任务，年龄不与场景同等权重。
- 场景库留给 Discover 页，Onboarding 只给 6 个高频入口。

## 3. 第一句练习

去掉句卡边框，英文直接浮在页面上。

页面结构：

1. 顶部栏：场景名 / `一句就够`，[返回] 和 [稍后]
2. 练习页不显示小禾气泡（V21 确认去掉，但用户后来改为保留场景动态文案，见第 4 节）
3. 句子展示区（无边框卡片）：
   - 场景 pill 标签
   - 句序计数
   - 英文主句：32px，Fraunces 字体
   - 中文释义：15px，柔和色
4. 发音播放：小图标按钮（🔊），放在英文句子旁
5. 底部主按钮：`说完了`，固定底部，≥56px
6. 底部次级按钮：`换一句`、`结束`，文字按钮

设计要求：

- 句子展示区不使用圆角边框和阴影，英文直接浮在页面上。
- 发音播放是小图标，不是独立按钮行。
- 播放中显示"播放中"文字，不显示进度条。
- 主按钮固定在屏幕底部，不随滚动消失。
- 点击"说完了"有轻触觉反馈。
- 不要求先播放再完成。
- 触控目标不小于 44px。

## 4. 练习页小禾气泡

V21 确认：保留小禾气泡，但改为场景动态文案。

规则：

1. 小禾在练习页只显示一行短提示，不进入连续聊天。
2. 文案随当前场景变化，像一个"懂你现在处境"的陪伴者。
3. 每句描述具体场景动作，暗示"说一句就好"的轻量感。
4. 不用"你"开头（避免指令感）。
5. 不超过 15 个字。

场景文案：

- 喂饭：`喂饭时轻轻说，宝宝会听的。`
- 喝水：`递水的时候说一句就好。`
- 换尿布：`换尿布时说，宝宝反而更安静。`
- 洗澡：`洗澡时说，宝宝会觉得好玩。`
- 睡前：`睡前轻轻说，像讲故事一样。`
- 出门：`出门前说一句，今天就开始了。`

## 5. 宝宝反应记录

增加图标 + 延长自动跳转时间。

交互规则：

1. 点击"说完了"后，本句立即保存。
2. 页面显示"已保存本句"。
3. 展示宝宝反应按钮，使用图标 + 文字组合：
   - 😊 有回应（绿色调）
   - 😌 安静了（蓝色调）
   - 😐 没反应（灰色调）
4. 选后自动跳转延长到 2.5-3 秒，显示可见倒计时进度条。
5. 用户可点击"下一句"立即跳过等待。
6. 点击"换一句"或"结束"取消自动跳转。
7. 不选反应则需点击"跳过，下一句"。

反馈文案不变：

- 有回应：`记下来了，小禾给你下一句。`
- 安静了：`记下来了，这句可以留着用。`
- 没反应：`没关系，换一句试试。`

设计要求：

- 反应按钮使用图标 + 文字，不依赖颜色作为唯一标识。
- 倒计时进度条使用轻量动画，不抢视觉焦点。
- 自动跳转可取消，避免竞态。

## 6. 年龄后置入口

V20 方案不变。

规则：

1. 首屏底部虚线框按钮：`宝宝多大？可稍后补`
2. 点击后展开月龄选择面板：0-6 月、7-12 月、13-18 月、19-36 月、先跳过。
3. 选择后按钮显示已选月龄。
4. 年龄可跳过；如后续实现让年龄影响推荐，必须真实影响句子难度。

## 7. 结束态

增加视觉记忆点和动态文案系统。

页面结构：

1. 顶部栏：`小禾老师 / 今天已完成`，[返回]
2. 小禾气泡：根据完成数量动态变化
   - 说了 1 句：`第一句最难，你已经开始了。`
   - 说了 2-3 句：`连续说了几句，宝宝有听到的。`
   - 说了 4+ 句：`今天说的比很多家长一周都多。`
3. 种子萌芽动画：
   - 从底部种子长出两片小叶，约 1.5s 缓动完成
   - 萌芽使用 #3B8577 绿色，种子使用暖棕色
   - 动画结束后文字区域淡入（0.3s）
   - 支持 prefers-reduced-motion：跳过动画，直接显示完整萌芽图
4. 主标题：根据场景动态变化
   - 喂饭：`喂饭时说的这句，下次还能用。`
   - 睡前：`睡前说的这句，会变成你们的小仪式。`
   - 洗澡：`洗澡时说的这句，宝宝会觉得好玩。`
   - 出门：`出门前说的这句，今天就开始了。`
   - 喝水：`喝水时说的这句，明天还能用。`
   - 换尿布：`换尿布时说的这句，宝宝会慢慢习惯。`
5. 总结固定行：`下次打开，小禾会给你新的一句。`
6. 总结可选追加（根据宝宝反应）：
   - 有回应：`刚才宝宝有回应的那句，可以留着多用几次。`
   - 没反应：`有些句子需要宝宝听几次才会有反应，这很正常。`
7. 主按钮：`再来一句`
8. 次按钮：`先到这里`

设计要求：

- 萌芽动画与 Garden 页面关联：结束页种下的萌芽就是 Garden 的第一颗种子。
- 动画只播放一次，不循环。
- 文字在动画完成后淡入，先看到画面再读文字。
- 结束页不展示排行榜、闯关、分数。

## 8. 可访问性与移动端要求

1. 所有主要按钮和反应按钮触控目标不小于 44px。
2. 小禾老师头像为装饰元素时应对屏幕阅读器隐藏；提示气泡需要有语义标签。
3. 交互元素需要有明显 focus 状态。
4. 支持 prefers-reduced-motion，自动下一句、播放状态和萌芽动画在减弱动效模式下不得造成阅读困难。
5. 页面不得出现横向滚动。
6. 文本字号在移动端保持可读，英文句子可以大，但不能溢出容器。
7. 反应按钮使用图标 + 文字，不依赖颜色作为唯一标识。

## 9. 已确认视觉原型

V21 原型：

- `qa-mobile-onboarding-v21-scene-first.html`

演进过程：

- V16 确认"直接说"主路径：听一下不是必经步骤。
- V17 确认英文优先和反应自动下一句方向。
- V18 引入"小禾老师一句式引导"。
- V19 根据产品经理审核精简入口、后置年龄、减少反应项、处理自动跳转竞态。
- V20 在新视觉会话中固化 V19 修正。
- V21 迭代交互细节：纵向列表场景选择、去掉句卡边框、弱化发音按钮、图标反应按钮、延长自动跳转、萌芽动画结束态、动态文案系统。

## 10. 与 V20 的差异清单

| 模块 | V20 | V21 |

| 场景默认 | 默认选中喂饭 | 根据时段智能默认 |

| 发音播放 | 独立按钮行 | 小图标按钮 |

## 11. 后续实现提示

1. Onboarding 与 practice 的边界：第一句可以作为 onboarding 结束后的第一张 practice 卡，但逻辑上应复用练习页能力。
2. 练习句来源应连接后端 LLM 生成接口，不能长期依赖静态本地句库。
3. 发音播放应连接后端 TTS 或统一音频服务，不能使用杂音或空路径。
4. 年龄字段若参与推荐，必须在请求参数和推荐结果中形成真实差异。
5. 宝宝反应保存后应驱动 garden 成长痕迹，但反应记录不得阻塞下一句。
6. 结束态萌芽动画需要与 Garden 页面的种子数据关联。
7. 场景动态文案需要与后端场景标签对齐，不能硬编码到前端。
8. 智能默认场景需要基于设备时间，不依赖用户时区设置（使用本地时间）。

## 12. UX 优化（基于 Onboarding 最佳实践研究）

以下优化基于 15 个成功 App 的 Onboarding 最佳实践研究确认。

### 12.1 去掉"开始一句"按钮

场景选中后自动进入练习页，不需要再点"开始一句"确认。

逻辑：用户选了场景就已经表达了意图，不需要额外确认步骤。

首屏底部只保留：
- `直接给一句`（次要文字按钮，跳过场景选择，使用默认场景）
- `先看看再说`（轻量文字按钮，给用户控制感）

### 12.2 声源统一原则

一个页面只有一个"说话的人"。去掉独立的文字引导，所有引导融入小禾气泡。

首屏小禾气泡更新为：
`选个正在发生的场景，小禾给你一句现在就能说的。`

既说明了操作（选场景），又说明了价值（给你一句能说的），不需要额外的文字引导。

练习页去掉"说完后，小禾会记录宝宝的反应"提示（用户说完了自然会看到反应选项，不需要提前告知）。

结束态的标题和总结保留（它们是事实陈述，不是引导），但小禾气泡不重复标题内容。

## 13. 微交互规范（基于 2026 移动端 UX 最佳实践）

### 13.1 触觉反馈

| 交互点 | 反馈类型 | 时机 |
|--------|---------|------|
| 选中场景 | 轻触觉 (light tap) | 场景按钮按下时 |
| 点击"说完了" | 中触觉 (medium tap) | 保存成功时 |
| 选择反应 | 轻触觉 (light tap) | 反应按钮按下时 |

Flutter 实现：使用 `HapticFeedback.lightTap()` 和 `HapticFeedback.mediumImpact()`。

### 13.2 按钮状态动画

| 按钮 | 按下动画 | 回弹时长 |
|------|---------|---------|
| 场景按钮 | scale(0.95) | 150ms ease-out |
| "说完了" | scale(0.97) | 150ms ease-out |
| 反应按钮 | scale(0.95) | 200ms ease-out |

设计要求：
- 所有按钮动画 < 100ms 触发视觉响应
- 回弹动画 < 200ms
- 支持 prefers-reduced-motion

### 13.3 页面转场

| 转场 | 方向 | 时长 |
|------|------|------|
| 场景选择 → 练习页 | 从右向左滑入 | 250ms ease-out |
| 练习页 → 结束态 | 从下向上推入 | 300ms ease-out |

设计要求：
- 顶部导航栏在转场中不跳变
- 使用 `SlideTransition` 或 `AnimatedSwitcher`
- 支持 prefers-reduced-motion（跳过动画，直接切换）
- 使用元素级联动转场，不是整页滑入
- 元素错开出现（stagger 50-80ms）
- 使用物理缓动曲线 `Curves.easeOutCubic` 或 `cubic-bezier(0.25, 0.1, 0.25, 1.0)`
- 退出元素也有动画（淡出+微缩）
- 背景色在转场中微变（暖纸→练习页色调）

场景选择 → 练习页转场序列：
1. 选中场景按钮 → 放大高亮 (200ms)
2. 其他场景按钮 → 淡出 (150ms)
3. 小禾气泡 → 切换文案 + 微移 (200ms)
4. 英文句子 → 从场景按钮位置飞入页面中央 (300ms)
5. "说完了"按钮 → 从底部推入 (250ms)

练习页 → 结束态转场序列：
1. "说完了"按钮 → 变为 "✓ 已保存" (200ms)
2. 反应按钮 → 依次淡入 (stagger 80ms)
3. 选择反应后 → 萌芽从底部生长 (1.5s)
4. 标题 → 萌芽完成后淡入 (300ms)
5. 按钮 → 最后淡入 (200ms)

### 13.4 庆祝动画时长

| 动画 | 时长 | 说明 |
|------|------|------|
| "✓ 已保存" 淡入 | 200ms | 轻量确认 |
| 反应选中放大 | 200ms | scale(1.05) → 回弹 |
| 萌芽动画 | 1.5s | 里程碑庆祝，可以更长 |
| 自动跳转倒计时 | 2.5-3s | 可见进度条 |

### 13.5 拇指区域优化

主要操作（底部 1/3 屏幕）：
- "说完了" 按钮：固定底部，拇指自然位置
- 反应按钮：底部区域
- 场景按钮：纵向列表，全屏可触达

次要操作（顶部 1/3）：
- "返回"：左上角
- "稍后"：右上角
- "直接给一句"：右上角

### 13.6 触控目标

所有交互元素最小 44x44px，推荐 48x48dp。

## 14. 状态处理

### 14.1 TTS 失败

- 显示重试消息："发音加载失败，点我重试"。
- 点击后重新请求 TTS，不自动重试。

### 14.2 短语获取失败

- 使用本地 fallback 短语库，覆盖 6 个场景各至少 5 句。
- Toast 提示："网络不佳，已为你准备离线短语"。

### 14.3 网络错误

- 进入离线模式，仅展示本地短语。
- 搜索和换一批功能降级，保留场景筛选。
- 顶部显示离线标识："离线模式"。
