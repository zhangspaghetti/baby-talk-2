本文件写给产品、设计和 Flutter 实现工程师。

读完后，读者应该能够：

## 2. 背景与目标

Shell 是 app 的全局导航框架，承载底部 Tab 切换、设置入口、账号入口和小禾导师入口。

目标：

1. 底部四 Tab 提供清晰的页面切换：首页、发现、花园、成长。
2. 左上角 Drawer 承载非主导航入口：提醒、宝宝档案、照护者偏好、播放偏好、帮助与反馈。
3. 右上角账号入口区分登录/未登录状态。
4. 小禾 FAB 在所有页面（除首页内联入口外）提供统一的导师入口。
5. 导航转场保持轻量，不打断用户当前任务。

非目标：

- 不在 Drawer 中重复主 Tab 入口。
- 不把账号入口做成全屏登录页。
- 不把小禾 FAB 做成聊天机器人入口。
- 不使用复杂动画或转场效果。
- 不在 Shell 中承载页面内容。

## 3. 底部导航栏

底部四 Tab 是 app 的主导航。

Tab 列表：

1. 首页 (home)
2. 发现 (discover)
3. 花园 (garden)
4. 成长 (growth)

视觉规格：

1. 高度：82px（含安全区）。
2. 背景：rgba(255, 252, 247, .92) + backdrop-filter: blur(18px)。
3. 顶部边框：1px solid rgba(88, 68, 48, .08)。
4. Tab 项：grid 布局，图标 + 文字，居中对齐。
5. 图标尺寸：20x20px。
6. 文字尺寸：11px，font-weight: 600。
7. 间距：图标与文字之间 4px。

状态：

1. 未选中：--text-muted 颜色，透明背景。
2. 选中：--sage-2 颜色，--sage-soft 背景，border-radius: 18px。
3. 切换时：背景色和文字颜色使用 180ms ease 过渡。

交互：

1. 点击 Tab 切换页面。
2. 当前页面 Tab 显示选中态。
3. 切换时页面内容区域滚动到顶部。
4. Tab 切换不触发页面重新加载，只切换 visibility。

设计要求：

1. Tab 触控目标不小于 44x58px。
2. 选中态不能只依赖颜色，需要有背景变化。
3. Tab 图标使用 CSS 伪元素绘制，不使用图片或 icon font。
4. 底部导航需要处理 iPhone 安全区域。

## 4. 左侧 Drawer

Drawer 承载非主导航入口。

入口列表：

1. 提醒时间：按照护节奏。
2. 宝宝档案：月龄与称呼。
3. 照护者偏好：妈妈、爸爸、老人。
4. 播放偏好：音量与语速。
5. 帮助与反馈：遇到问题。

触发方式：

1. 点击左上角汉堡菜单按钮。
2. 按钮尺寸：46x46px。
3. 按钮样式：--line 边框，--warm 颜色，18px 三横线图标。

Drawer 视觉规格：

1. 从底部弹出的 sheet 样式（非侧边抽屉）。
2. 最大高度：屏幕高度的 66%。
3. 顶部圆角：28px。
4. 背景：rgba(255, 252, 247, .98)。
5. 阴影：0 -18px 48px rgba(80, 57, 35, .18)。
6. 遮罩层：rgba(48, 40, 32, .16)。

交互：

1. 点击菜单按钮打开 sheet。
2. sheet 从底部滑入，遮罩层淡入。
3. 点击遮罩层或关闭按钮关闭 sheet。
4. 关闭后焦点返回触发按钮。

设计要求：

1. 入口列表使用 grid 布置，每项 48px 高。
2. 每项有左右两列：左侧名称，右侧说明。
3. 说明文字使用 --text-muted 颜色。
4. 触控目标不小于 44px。

## 5. 账号入口

账号入口固定在右上角。

视觉规格：

1. 按钮尺寸：最小 44px 高度。
2. 包含同步状态指示点和"账号"文字。
3. 同步状态点：9px 圆形，颜色根据状态变化。

状态：

1. 未登录：琥珀色同步点，文字"账号"。
2. 已登录-同步中：琥珀色同步点，文字"同步中"。
3. 已登录-已同步：青绿色同步点，文字"已同步"。
4. 已登录-同步失败：红色同步点，文字"同步失败"。

交互：

1. 点击打开账号 sheet。
2. sheet 展示登录/同步状态和操作按钮。
3. 未登录时强调"登录后同步今天说过的句子和花园痕迹"。
4. 已登录时展示账号信息和退出登录选项。

设计要求：

1. 账号入口不能阻断主路径。
2. 未登录状态使用轻提示，不强制弹出。
3. 同步状态使用用户能理解的语言，不暴露技术词。

## 6. 小禾 FAB

小禾 FAB 是全局导师入口，出现在所有页面。

定位：

1. 右下角固定定位。
2. 底部偏移：导航栏高度 + 14px。
3. 右侧偏移：20px。

视觉规格：

1. 最小高度：54px。
2. 包含小禾标记图标和"问小禾"文字。
3. 背景：rgba(255, 252, 247, .94)。
4. 边框：1px solid rgba(87, 119, 104, .2)。
5. 阴影：0 16px 34px rgba(80, 57, 35, .16)。
6. 圆角：18px。
7. backdrop-filter: blur(16px)。

特殊规则：

1. 首页使用内联"问小禾"入口，FAB 隐藏。
2. Practice 页 FAB 保留，但不遮挡"读一下"或"说完了"按钮。
3. 其他页面 FAB 正常显示。

交互：

1. 点击打开小禾面板。
2. 面板从底部弹出，包含场景选择和问答能力。
3. 关闭后返回原页面上下文。

设计要求：

1. FAB 不遮挡主要内容区域。
2. 小屏下 FAB 收缩为纯圆形图标按钮。
3. FAB 的 z-index 高于页面内容但低于 sheet。

## 7. 顶部栏

顶部栏在所有页面保持一致。

结构：

1. 左侧：汉堡菜单按钮（46x46px）。
2. 中间：BabyTalk 标题 + 副标题。
3. 右侧：账号入口。

视觉规格：

1. 高度：64px。
2. 背景：rgba(255, 252, 247, .62)。
3. 底部边框：1px solid rgba(88, 68, 48, .08)。
4. 标题字号：17px，font-weight: 700。
5. 副标题字号：12px，font-weight: 600。

副标题变化：

1. 首页：`每天一句亲子英语`
2. 发现：`每天一句亲子英语`
3. 花园：`每天一句亲子英语`
4. 成长：`每天一句亲子英语`

设计要求：

1. 顶部栏在页面滚动时保持固定。
2. 标题和副标题不换行，溢出时使用省略号。
3. 按钮和标题之间保持 10px 间距。

## 8. 导航转场

Tab 切换使用轻量转场。

规则：

1. Tab 切换不使用页面级动画。
2. 内容区域使用 visibility 切换，不使用 display: none。
3. 切换时新页面从滚动位置 0 开始。
4. 不保留前一个页面的滚动位置（Phase 1 简化）。

Sheet 打开/关闭：

1. 打开：从底部滑入，250ms ease-out。
2. 关闭：向下滑出，200ms ease-in。
3. 遮罩层：淡入 250ms，淡出 200ms。

设计要求：

1. 转场动画支持 prefers-reduced-motion。
2. 减弱动效模式下跳过所有过渡动画。
3. 转场过程中用户操作不被阻断。

## 9. 状态矩阵

| 状态 | 用户看到 |
| --- | --- |
| 页面加载中 | 顶部栏和底部导航立即显示，内容区显示骨架。 |
| Tab 切换 | 平滑切换，新页面从顶部开始。 |
| 离线 | 顶部栏显示离线状态，账号入口显示离线提示。 |
| 登录状态变更 | 账号入口状态实时更新，不刷新页面。 |
| 小禾失败 | FAB 保持可见，打开面板后显示本地建议。 |

## 10. 视觉系统要求

Shell 必须对齐 `DESIGN.md`。

字体：

1. 标题使用 DM Sans 或 PingFang SC。
2. Tab 文字使用 DM Sans 或 PingFang SC。
3. 不使用 Fraunces（仅用于英文短语显示）。

颜色：

1. 顶部栏背景：rgba(255, 252, 247, .62)。
2. 底部导航背景：rgba(255, 252, 247, .92)。
3. 选中态：--sage-soft 背景，--sage-2 文字。
4. 未选中态：--text-muted 文字。
5. 边框：rgba(88, 68, 48, .08)。

视觉要求：

1. 不使用紫色、蓝紫渐变。
2. 不使用 emoji 作为设计元素。
3. 阴影应克制。
4. 圆角使用层级系统：小元素 8-16px，大容器 24-28px。

## 11. 响应式与可访问性

小屏适配：

1. 320/360 宽度下，底部导航保持 4 Tab 不变。
2. 小屏下 FAB 收缩为纯圆形图标按钮（46x46px）。
3. 顶部栏标题和副标题使用省略号处理溢出。
4. Sheet 在小屏下最大高度调整为 80%。

可访问性要求：

1. 所有导航元素有清晰的语义标签。
2. Tab 使用 role="tablist" 和 role="tab"。
3. Sheet 使用 role="dialog" 和 aria-modal="true"。
4. 选中态使用 aria-selected 或 aria-current="page"。
5. 支持 TalkBack/VoiceOver 基础路径测试。
6. 支持 prefers-reduced-motion。

## 12. 后续实现提示

实现 Shell 时需要重点关注：

1. Flutter Navigator 2.0 或 go_router 需要支持 Tab 切换和深层链接。
2. 底部导航需要处理 iPhone 安全区域（SafeArea）。
3. Sheet 组件需要可复用，Drawer、账号和小禾面板共用。
4. 状态管理需要区分页面级状态和全局状态。
5. 离线状态需要与后端同步状态联动。
6. 字体资源需要按 `DESIGN.md` 打包。
7. 验证 320、360、430 宽度，以及 TalkBack/VoiceOver 基础路径。
