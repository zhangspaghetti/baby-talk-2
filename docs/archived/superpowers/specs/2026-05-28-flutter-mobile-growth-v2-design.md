# Flutter Mobile Growth V2 成长页交互结论

日期：2026-05-28
状态：Growth V2 子设计已确认（基于 V1 迭代，参照微信读书阅读时长页面）
前序版本：2026-05-28-flutter-mobile-growth-design.md (V1)

## 1. 背景与目标

V1 是单一视图的总量摘要 + 场景覆盖 + 里程碑列表。V2 参照微信读书"阅读时长"页面的多维度切换模式（周/月/年/总），增加"旅程"tab 展示里程碑时间线。

Growth 页从"我"页面的"成长数据入口块"进入。

## 2. 页面结构

```text
顶部栏
  ← 我的成长

维度切换 tab
  [周] [月] [年] [总] [旅程]

当前维度内容（根据选中 tab 变化）
```

## 3. 周维度

```text
本周说了 8 句
覆盖 3 个场景

每日柱状图（周一→周日）
  ┌─┬─┬─┬─┬─┬─┬─┐
  │ │█│ │█│█│ │ │
  │ │█│ │█│█│█│ │
  └─┴─┴─┴─┴─┴─┴─┘
  一 二 三 四 五 六 日

本周场景
  喂饭 · 3 句
  睡前 · 3 句
  洗澡 · 2 句

花园状态
  🌱 发芽 · 7/10 次施肥
  再说 3 句就开花了
```

设计要求：

1. 摘要是页面第一视觉锚点。
2. 每日柱状图轻量，不抢视觉重心。
3. 场景列表简洁，按句数降序。
4. 花园状态放在底部，与 Garden V2 关联。

## 4. 月维度

```text
本月说了 32 句
覆盖 5 个场景

每周柱状图（W1→W4/W5）
  本周场景覆盖详情

花园状态
  本月施肥 12 次
  当前阶段：含苞
```

## 5. 年维度

```text
今年说了 247 句
覆盖 6 个场景
坚持 45 天

每月柱状图（1月→12月）

年度里程碑
  ✓ 第一句英语        5月10日
  ✓ 覆盖3个场景       5月20日
  ✓ 累计100句         6月15日
  ○ 累计500句         还差253句
```

## 6. 总维度

```text
累计说了 247 句
覆盖 6 个场景
坚持 45 天

花园成长时间线
  种子 → 发芽 → 含苞 → 盛开 → 结果
  当前：含苞（已施肥 18/25 次）

全部里程碑列表
```

## 7. 旅程 tab

旅程 tab 展示里程碑时间线，类似微信读书的"阅历"。

```text
你的成长旅程

🌱 5月10日
第一句英语
"One more bite."

🌱 5月12日
第一次睡前场景
"Time to sleep."

🌿 5月18日
累计 10 句
花从种子长到了发芽

🌿 5月25日
覆盖 3 个场景
喂饭 · 睡前 · 洗澡

○ 累计 50 句
还差 3 句
```

设计要求：

1. 里程碑按时间倒序排列。
2. 已完成里程碑使用完整卡片样式。
3. 未完成里程碑使用轻量提示，显示"还差 N 句"。
4. 每个里程碑关联花园成长阶段变化。
5. 点击里程碑可查看详情。

## 8. 里程碑定义

| 里程碑 | 触发条件 | 关联花园阶段 |
|--------|---------|-------------|
| 第一句英语 | 说了第 1 句 | 种子→发芽 |
| 第一次喂饭场景 | 喂饭场景说了第 1 句 | — |
| 第一次睡前场景 | 睡前场景说了第 1 句 | — |
| 第一次洗澡场景 | 洗澡场景说了第 1 句 | — |
| 累计 10 句 | 总共说了 10 句 | 发芽→含苞 |
| 覆盖 3 个场景 | 覆盖了 3 个不同场景 | — |
| 累计 25 句 | 总共说了 25 句 | 含苞→盛开 |
| 覆盖 6 个场景 | 覆盖了全部 6 个场景 | — |
| 累计 50 句 | 总共说了 50 句 | 盛开→结果 |

## 9. 下一步建议

在周/月维度底部，显示温和的下一步建议：

```text
下一步
  你还没试过洗澡场景。
  试试 "Splash splash"
  [试这一句]
```

设计要求：

1. 建议基于用户未覆盖的场景。
2. 推荐一个具体短语。
3. 点击直接进入 Practice。
4. 不做强制引导，保持温和。

## 10. 空态

首次进入或无数据时：

1. 主文案：`还没有练习记录。`
2. 辅助文案：`说完第一句英文后，这里会显示你的成长数据。`
3. 主按钮：`去说一句`

## 11. 与 V1 的差异清单

| 模块 | V1 | V2 |
|------|-----|-----|
| 维度切换 | 无 | 周/月/年/总/旅程 5 个 tab |
| 数据展示 | 单一总量摘要 | 按维度切换的摘要 + 图表 |
| 里程碑 | 独立列表 | 旅程 tab 内的时间线 |
| 花园关联 | 无 | 每个维度底部显示花园状态 |
| 下一步建议 | 无 | 周/月维度底部的温和建议 |
| 入口 | 独立 Tab | "我"页面内的入口块 |

## 12. 后续实现提示

1. Growth 数据需要按维度聚合，需要定义时间维度查询接口。
2. 每日/每周/每月柱状图使用轻量 chart 组件。
3. 里程碑数据与花园成长阶段共享数据源。
4. 下一步建议需要分析用户场景覆盖情况。
5. "旅程"tab 需要支持增量加载。

本文件仅记录已确认的 Growth V2 子设计，不代表实现计划已经批准。
