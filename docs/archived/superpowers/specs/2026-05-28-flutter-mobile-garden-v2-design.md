# Flutter Mobile Garden V2 花园页交互结论

日期：2026-05-28
状态：Garden V2 子设计已最终确认（基于 V1 迭代，芭芭农场式，所有参数可配置）
前序版本：2026-05-28-flutter-mobile-garden-design.md (V1)

## 1. 背景与目标

V1 设计是纯练习痕迹列表，缺少"成长感"的视觉表达。V2 参考芭芭农场的核心循环（做任务→得肥料→领取→施肥→树长大），将花园从日志列表改为**单株成长模型**。

核心循环映射：

```
芭芭农场：做任务 → 得肥料 → 领取 → 施肥 → 树长大
BabyTalk：说英文 → 得肥料 → 领取 → 施肥 → 花长大
```

目标：

1. 让家长通过"照顾一株花"的隐喻感受练习的价值。
2. 肥料领取和施肥创造主动参与感，不是被动记录。
3. 成长阶段（种子→发芽→含苞→盛开→结果）提供长期目标。
4. 与 Onboarding V21 的萌芽动画自然衔接。

非目标：

- 不做花圃地图或多株花系统（Phase 1 只有一株）。
- 不做浇水、除草等复杂操作。
- 不做社交分享或好友助力。
- 不做兑换真实奖励。

## 2. 核心循环

```
说英文（Practice 点"说完了"）
    ↓
产生肥料包（自动，花园显示红点提示）
    ↓
进入花园，看到"待领取"肥料
    ↓
点击"领取肥料"（手动，制造"我拿到了"的参与感）
    ↓
点击"施肥"按钮（手动，制造"我在照顾它"的拥有感）
    ↓
花成长一点（微动画：肥料撒下 → 花轻轻摇晃）
    ↓
进度条推进，阶段变化时有庆祝动画
```

## 3. 页面结构

```text
顶部栏
  返回 / 花园

花的可视化区
  当前阶段的花（CSS/SVG 动画）
  成长阶段标签（如"发芽阶段"）
  进度条（已施肥 N/总 次）
  进度提示（如"再说 3 句就开花了"）

肥料背包区
  肥料包数量（如"你有 3 包肥料"）
  [施肥] 按钮

肥料来源区（最近练习痕迹）
  待领取的肥料列表（带"领取"按钮）
  已领取的肥料列表（灰色，已转化为施肥）
```

## 4. 成长阶段

| 阶段 | 视觉 | 需要施肥次数 | 触发条件 |
|------|------|------------|---------|
| 种子 | 埋在土里 | 0 | Onboarding 完成后自动种下 |
| 发芽 | 小芽破土 | 3 次 | 施肥 3 次 |
| 含苞 | 花苞出现 | 10 次 | 累计施肥 10 次 |
| 盛开 | 花朵绽放 | 25 次 | 累计施肥 25 次 |
| 结果 | 结出果实 | 50 次 | 累计施肥 50 次 |

设计要求：

- 花的视觉从种子到盛开有连续过渡，不是跳变。
- 阶段变化有庆祝动画（类似 Onboarding V21 的萌芽动画，但更大）。
- 当前阶段和下一阶段之间显示"再说 N 句"的进度提示。
- 支持 prefers-reduced-motion。

## 5. 肥料系统

肥料产生规则：

- 每说一句英文 → 产生 1 包肥料。
- 肥料不自动施加，需要手动领取。
- 花园 Tab 显示红点提示有新肥料待领取。

肥料领取交互：

1. 进入花园页面，看到"待领取"肥料列表。
2. 每条肥料显示：英文短语 + 场景 + 时间。
3. 点击"领取"按钮，肥料进入背包。
4. 领取有微动画（肥料包飞入背包）。

施肥交互：

1. 背包区显示当前肥料数量。
2. 点击"施肥"按钮。
3. 施肥动画：肥料撒下 → 花轻轻摇晃 → 进度条推进。
4. 每次施肥消耗 1 包肥料。
5. 施肥后背包数量减少。

## 6. 肥料来源列表

肥料来源是练习痕迹的变体，保留 V1 的日志功能。

条目状态：

1. 待领取：显示英文短语 + 场景 + 时间 + [领取] 按钮。
2. 已领取：灰色显示，标记"已领取"。
3. 已施肥：不单独显示，合入进度。

设计要求：

- 待领取条目视觉权重高于已领取。
- 列表按时间倒序。
- 空态："还没有肥料，去说一句英文吧。"

## 7. 空态

首次进入花园或 Onboarding 后的空态：

1. 显示种子埋在土里的动画。
2. 主文案：`你的种子已经种下了。`
3. 辅助文案：`说完第一句英文，花园里就会出现第一包肥料。`
4. 主按钮：`去说一句`

设计要求：

- 空态与 Onboarding V21 的萌芽动画衔接。
- 不使用鼓励性过强的文案。

## 8. 与 Onboarding V21 的衔接

- Onboarding 结束页的萌芽动画 = 花园的种子阶段。
- 用户从 Onboarding 出来时，花园里已经有一颗种子在等他们。
- 第一次说英文后，花园出现第一包肥料。
- 领取 + 施肥后，种子发芽。

## 9. 与 Home 花园摘要的衔接

Home 花园摘要（"今日痕迹 / 小芽"）是花园页的入口之一。

衔接规则：

1. Home 完成一句后，花园摘要展开显示"有新肥料待领取"。
2. 点击花园摘要或底部导航"花园"Tab 进入花园页。
3. 花园页打开后，如果有待领取肥料，自动滚动到肥料列表。

## 10. 视觉系统要求

花的可视化：

1. 使用 CSS/SVG 动画，不使用 Lottie 或 GIF。
2. 花的颜色使用 #3B8577（sage green）为主色。
3. 土壤使用暖棕色。
4. 背景保持 #FFF8F0 暖纸色。

肥料包视觉：

1. 肥料包使用轻量图标（如小袋子或水滴形状）。
2. 待领取：暖色高亮。
3. 已领取：灰色 + 勾选标记。

动画：

1. 施肥动画：0.5s 缓动。
2. 阶段变化动画：1.5s，与 Onboarding 萌芽动画风格一致。
3. 支持 prefers-reduced-motion。

## 11. 后续实现提示

1. 花的成长状态需要持久化（Isar 本地数据库）。
2. 肥料产生和领取需要记录，支持离线操作。
3. 施肥动画需要与花的 SVG 状态联动。
4. 阶段变化需要触发通知或 Home 花园摘要更新。
5. 底部导航安全区需要正确处理。

本文件仅记录已确认的 Garden V2 子设计，不代表实现计划已经批准。
