Shell V1 导航审核稿

Shell 是 app 的全局导航框架，包含底部四 Tab、顶部栏、Drawer、账号入口和小禾 FAB。三台手机分别展示：首页+Drawer、发现+FAB、账号状态。

关键设计

  • 底部四 Tab 使用 CSS 伪元素绘制图标，选中态用 --sage-soft 背景 + --sage-2 文字。
  • Drawer 采用底部 sheet 样式，从底部滑入，最大高度 66%。
  • 小禾 FAB 在首页隐藏（首页用内联入口），其他页面右下角固定。
  • 账号入口区分未登录（琥珀点）、已同步（绿点）、同步失败（红点）三种状态。
  • 顶部栏在所有页面保持一致：菜单 / BabyTalk / 账号。

规则

  • Drawer 不承载主 Tab 入口，只放设置类功能。
  • FAB 不遮挡主要内容和主按钮。
  • 账号入口不阻断主路径，未登录时可继续体验。
  • 所有触控目标不小于 44px。
  • 转场动画支持 prefers-reduced-motion。
