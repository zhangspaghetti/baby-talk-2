# Flutter Mobile Discover 发现页交互结论

日期：2026-05-28
状态：Discover 子设计已确认（待合入整体 QA 迭代设计）

## 1. 读者与读完后动作

本文件写给产品、设计和 Flutter 实现工程师。

读完后，读者应该能够：

1. 判断 Discover 页与 Home、Practice 页的职责边界。
2. 按 Discover V1 的信息架构实现 Flutter 发现页。
3. 为搜索、筛选、场景浏览和空状态设计用户可见反馈。
4. 验收发现页是否符合 `DESIGN.md` 的 Warm Paper Kindness 方向。

本文件不是实现计划，也不直接批准生产代码改动。进入实现前仍需要拆分任务、确认数据契约和测试范围。

## 2. 背景与目标

Discover 页是家长主动探索短语库的入口。Home 负责"今天先说哪一句"，Discover 负责"还想看看别的场景和句子"。

目标：

1. 让家长可以按场景浏览短语库，不感到像课程目录。
2. 提供轻量搜索和筛选，帮助家长快速找到眼前需要的句子。
3. 每条短语可以直接进入一次练习，不需要先收藏或加入计划。
4. 页面保持 Warm Paper Kindness：温暖、克制、亲切，不是学习任务清单。

非目标：

- 不把 Discover 做成课程分类页或闪卡墙。
- 不要求用户先完成今日短语才能浏览。
- 不在 Discover 中承载完整练习流程（点击后进入 Practice）。
- 不向用户暴露 TTS、LLM、接口、模型等技术词。
- 不使用 emoji、花哨动效或装饰性渐变。

## 3. 页面职责边界

Home 是今日编排页，Practice 是当前执行页，Discover 是场景浏览页。

Discover 承载：

1. 场景短语库浏览。
2. 按场景分类的短语列表。
3. 轻量搜索和筛选。
4. 短语预览与进入练习入口。
5. 随机推荐或"换一批"能力。

Home 承载：今日短语、今日活动、花园痕迹、小禾问答。

Practice 承载：当前一句的执行。

关键边界：Discover 解释"还有什么可以说的"，Home 解释"今天先说什么"，Practice 帮用户"把这一句说完"。

## 4. 信息架构

发现页首屏优先级：

1. 顶部搜索栏：轻量搜索，不抢视觉重心。
2. 场景横滑筛选：喂饭、喝水、换尿布、洗澡、睡前、出门等场景标签。
3. 短语列表：按当前选中场景展示短语卡片，每张卡片可直接进入练习。
4. 换一批：底部轻入口，随机推荐新一批短语。

结构：

```text
顶部栏
  菜单 / BabyTalk / 账号

搜索栏
  搜索短语或场景...

场景筛选
  全部 / 喂饭 / 喝水 / 换尿布 / 洗澡 / 睡前 / 出门

短语列表
  场景标签 + 英文短语 + 中文释义 + 进入练习
  场景标签 + 英文短语 + 中文释义 + 进入练习
  ...

换一批
  换一批短语

全局
  底部四 Tab：首页 / 发现 / 花园 / 我
  左上角 Drawer：提醒、宝宝档案、照护者偏好、播放偏好、帮助与反馈
  右下角小禾 FAB
```

## 5. 默认发现页态

默认态文案：

- 顶部标题：`BabyTalk`
- 顶部副标题：`每天一句亲子英语`
- 搜索占位：`搜索短语或场景...`
- 场景筛选默认：`全部`
- 列表空态：`这个场景还没有短语，换个场景试试。`
- 换一批：`换一批短语`

设计要求：

1. 搜索栏保持轻量，不做全屏搜索页。
2. 场景筛选使用横滑 pill，不使用下拉或弹窗。
3. 短语列表使用单列卡片流，不使用网格。
4. 每张卡片保持克制，不展示过多信息。
5. 空态使用友好文案，不让页面看起来"坏了"。

## 6. 场景筛选

场景筛选是 Discover 的核心导航。

场景列表：

1. 全部
2. 喂饭
3. 喝水
4. 换尿布
5. 洗澡
6. 睡前
7. 出门

交互：

1. 默认选中"全部"，展示所有场景的短语。
2. 点击场景 pill 切换筛选，列表平滑更新。
3. 选中态使用 --accent 高亮，未选中态使用 --bg-sunken。
4. 横滑可溢出，小屏下不强制展示全部 pill。

设计要求：

1. 场景 pill 触控目标不小于 44px。
2. 选中态不能只依赖颜色，需要有语义状态（如边框或下划线）。
3. 横滑时保持惯性滚动，不卡顿。

## 7. 短语卡片

短语卡片是 Discover 的核心内容单元。

内容：

1. 场景标签：如 `喂饭`。
2. 英文短语：使用 Fraunces 字体，--english 颜色。
3. 中文释义：小号辅助文字。
4. 进入练习按钮：`练这一句`。

交互：

1. 点击卡片任意区域或"练这一句"按钮进入 Practice。
2. 进入 Practice 时携带场景标签和短语数据。
3. 卡片之间保持 8px 间距。

设计要求：

1. 英文短语必须是卡片内最醒目的文字。
2. 中文释义只做辅助，不抢英文视觉重心。
3. 场景标签使用 pill 样式，与 Home 和 Practice 保持一致。
4. 卡片使用 --bg-surface 背景，--shadow-sm 阴影。
5. 触控目标不小于 44px。

## 8. 搜索

搜索是 Discover 的辅助能力，不是主路径。

交互：

1. 点击搜索栏展开键盘。
2. 输入关键词后实时筛选短语列表。
3. 支持按英文短语和中文释义搜索。
4. 搜索结果为空时展示友好空态。
5. 清空搜索后恢复默认列表。

设计要求：

1. 搜索栏使用 --bg-sunken 背景，--radius-sm 圆角。
2. 搜索图标使用 16px，放在左侧。
3. 不使用全屏搜索页或搜索结果弹窗。
4. 搜索不阻断场景筛选的切换。

## 9. 换一批

换一批是 Discover 的轻量推荐能力。

交互：

1. 点击"换一批短语"按钮。
2. 列表平滑更新为新一批短语。
3. 保持当前场景筛选状态。

设计要求：

1. 换一批按钮使用次级样式，不抢主视觉。
2. 按钮位于列表底部，不悬浮遮挡内容。
3. 换一批后不改变页面滚动位置。

## 10. 状态矩阵

| 状态 | 用户看到 |
| --- | --- |
| 加载中 | 保留顶部与底部导航，短语列表显示暖纸骨架，不显示空白卡。 |
| 空场景 | 提示"这个场景还没有短语，换个场景试试"，保留场景筛选。 |
| 搜索无结果 | 提示"没有找到匹配的短语，换个关键词试试"，保留搜索栏。 |
| 离线 | 标明"离线也能浏览已缓存的短语"，搜索和换一批降级。 |
| 网络失败 | 提示"短语加载失败，点我重试"，保留场景筛选。 |

## 11. 视觉系统要求

Discover V1 必须对齐 `DESIGN.md`。

字体：

1. 英文短语使用 Fraunces。
2. 中文 UI 使用 PingFang SC、Noto Sans SC、Microsoft YaHei 或等价 Flutter 字体栈。
3. 英文 UI 使用 DM Sans。

颜色：

1. 主背景：`#FFF8F0`。
2. 主 CTA：`#FF8C42`。
3. 英文短语高亮：`#3B8577`。
4. 英文柔和背景：`#D4E8E3`。
5. 文本使用 Warm Paper Kindness 的暖灰层级。

视觉要求：

1. 不使用紫色、蓝紫渐变或儿童教育类高饱和配色。
2. 不使用 emoji 作为设计元素。
3. 不使用大面积装饰光斑、渐变球或无意义图标墙。
4. 卡片只在承载真实交互时使用。
5. 阴影应克制，移除阴影后页面仍应有清晰层级。
6. 中文模块标题和按钮避免过重字重。

## 12. 响应式与可访问性

小屏优先级：

1. 320/360 宽度下，首屏优先保住搜索栏、场景筛选和第一张短语卡。
2. 短语卡片允许下滑出现。
3. 不允许横向滚动（场景筛选除外）。
4. 主要按钮不小于 44px，推荐 48px。

可访问性要求：

1. 搜索栏、场景筛选、短语卡片和换一批按钮都有清晰语义。
2. 场景筛选选中态不能只依赖颜色，需要有语义状态。
3. 搜索结果使用局部状态播报。
4. 不要把整页作为 live region，避免重渲染触发整屏播报。
5. 支持 TalkBack/VoiceOver 基础路径测试。
6. 支持减少动画设置。

## 13. 后续实现提示

实现 Discover V1 时需要重点关注：

1. 短语数据需要从后端获取，不能只依赖本地静态数据。
2. 搜索需要支持英文和中文的模糊匹配。
3. 换一批需要调用后端推荐接口，不能只做前端随机。
4. 场景筛选需要与 Home 和 Practice 的场景体系保持一致。
5. 进入 Practice 时需要携带场景标签和短语数据。
6. 字体资源需要按 `DESIGN.md` 打包。
7. 验证 320、360、430 宽度，以及 TalkBack/VoiceOver 基础路径。

## 16. Review 追加决策（2026-05-28）

以下 3 条决策在页面 review 中确认，补充到 Discover 设计中：

### 16.1 明确与 Home 的职责区分

Home 今日活动 = 轻活动建议（30 秒-2 分钟的小任务，如 TPR 小动作、绘本一页）。
Discover 短语库 = 可说的英文句子（纯短语，不含活动指导）。

用户理解：Home 告诉我"今天做什么活动"，Discover 告诉我"还能说什么句子"。

### 16.2 短语卡片增加使用上下文

每张短语卡片增加一行轻提示，说明这句话适合什么情况下说。

卡片内容更新为：
1. 场景标签：如 `喂饭`。
2. 英文短语：使用 Fraunces 字体，--english 颜色。
3. 中文释义：小号辅助文字。
4. 使用提示：如 `适合递勺前后轻轻说一次`（来自后端的 usageHint 字段）。
5. 进入练习按钮：`练这一句`。

### 16.3 去掉"换一批"，用排序替代

去掉列表底部的"换一批短语"按钮，改为场景内排序：

排序规则：
1. 最常用：按练习次数降序。
2. 最新：按添加时间降序。
3. 全部：按默认顺序。

排序入口放在场景筛选 pill 右侧，使用轻量下拉选择器。
