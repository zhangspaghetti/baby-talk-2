# Flutter Mobile Shell V2 导航交互结论

日期：2026-05-28
状态：Shell V2 子设计已确认（基于 V1 迭代，参照微信读书"我"页面）
前序版本：2026-05-28-flutter-mobile-shell-nav-design.md (V1)

## 1. 背景与目标

V1 使用四 Tab（首页/发现/花园/成长）+ Drawer 底部弹出 sheet。V2 调整为：

1. 底部 Tab 第四项从"成长"改为"我"。
2. 成长页变为"我"页面内的一个入口块。
3. Drawer 从底部弹出 sheet 改为独立设置页面（右上角齿轮图标进入）。
4. 参照微信读书"我"页面的内容布局。

## 2. 底部导航栏

底部四 Tab：

1. 首页 (home)
2. 发现 (discover)
3. 花园 (garden)
4. 我 (me)

视觉规格不变（82px 高，毛玻璃背景，图标+文字）。

## 3. "我" 页面

"我"页面是用户个人信息和功能入口的聚合页。

页面结构：

```text
顶部栏
  我的 / ⚙️ 设置图标

用户信息区
  头像 + 昵称（如"林林妈妈"）
  宝宝信息（如"宝宝 13个月 · 喂饭场景"）

花园状态入口块
  当前花的阶段（如"🌱 发芽阶段"）
  施肥进度（如"已施肥 7/10 次"）
  进度提示（如"再说 3 句就开花了"）
  点击进入花园页

成长数据入口块
  练习总量（如"47 句 · 6 场景"）
  坚持天数（如"坚持 18 天"）
  点击进入成长详情页（Growth 页）

功能入口网格（2列布局）
  🔔 提醒设置
  👶 宝宝档案
  🎵 播放偏好
  ❓ 帮助与反馈
```

设计要求：

1. 用户信息区保持简洁，不展示过多数据。
2. 花园状态入口块是页面第一视觉锚点（与微信读书"阅读时长"位置对应）。
3. 成长数据入口块是第二视觉锚点。
4. 功能入口网格使用 2 列布局，每项 48px 高。
5. 右上角设置图标 46x46px，点击进入设置页面。

## 4. 设置页面

设置是独立页面，不是底部弹出 sheet。

入口：点击"我"页面右上角齿轮图标。

页面结构：

```text
顶部栏
  ← 设置

设置列表
  提醒时间    按照护节奏 >
  宝宝档案    月龄与称呼 >
  照护者偏好  妈妈/爸爸/老人 >
  播放偏好    音量与语速 >
  帮助与反馈  遇到问题 >
  关于        版本信息 >
```

设计要求：

1. 设置页面使用标准列表布局，每项 56px 高。
2. 左侧名称，右侧说明 + 箭头。
3. 说明文字使用 --text-muted 颜色。
4. 页面使用右滑返回手势。
5. 不使用底部弹出 sheet。

## 5. 小禾 FAB

小禾 FAB 在所有页面（除首页内联入口外）提供统一的导师入口。

特殊规则：

1. 首页：使用内联"问小禾"按钮，不显示 FAB。
2. 花园页：FAB 隐藏（因为花园有自己的施肥交互）。
3. 其他页面：FAB 固定在右下角。

视觉规格：

1. 尺寸：56x56px。
2. 背景：暖纸色 + 细边框。
3. 图标：小禾头像缩略图。
4. 阴影：--shadow-md。

## 6. 账号入口

账号入口在"我"页面的用户信息区，不是右上角。

状态：

1. 未登录：显示"登录后同步数据"轻提示。
2. 已登录：显示头像 + 昵称。
3. 同步中：头像旁显示轻量同步指示器。

## 7. 导航转场

1. Tab 切换：页面内容区域滚动到顶部，visibility 切换。
2. 进入子页面（花园详情、成长详情、设置）：右滑进入，左滑返回。
3. 不使用复杂动画或转场效果。

## 8. 与 V1 的差异清单

| 模块 | V1 | V2 |
|------|-----|-----|
| 底部 Tab | 首页/发现/花园/成长 | 首页/发现/花园/我 |
| 成长页 | 独立 Tab | "我"页面内的入口块 |
| 设置入口 | 左上角汉堡菜单 → 底部 sheet | "我"页面右上角齿轮 → 独立页面 |
| 账号入口 | 右上角 | "我"页面用户信息区 |
| 小禾 FAB | 所有页面（除首页） | 所有页面（除首页和花园） |

## 9. 后续实现提示

1. Shell 需要支持四 Tab + 子页面栈。
2. "我"页面需要聚合花园状态和成长数据。
3. 设置页面需要独立路由。
4. 小禾 FAB 需要按页面条件显示/隐藏。
5. 底部导航安全区需要正确处理。

本文件仅记录已确认的 Shell V2 子设计，不代表实现计划已经批准。
