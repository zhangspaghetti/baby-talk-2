# Onboarding V21 讨论结论汇总

日期：2026-05-28
状态：最终确认
参与者：产品、设计、原型师

## 1. 讨论概览

本轮 Onboarding 页面讨论覆盖了 V20 已确认设计的所有交互细节，并基于行业研究进行了 UX 优化。讨论分为 6 个模块，每个模块都经过设计分析、方案对比和确认。

## 2. 场景选择

### 讨论过程
- 初始方案：2×3 网格布局
- 设计师意见：网格在小屏上容易误触，且 Onboarding 不需要展示全部场景
- 用户反馈：Onboarding 只需要 6 个高频场景，场景库留给 Discover 页

### 最终确认
- 布局：大按钮纵向列表（非 2×3 网格）
- 场景数量：6 个（喂饭/喝水/换尿布/洗澡/睡前/出门）
- 默认选中：根据时段智能推断（7-9→喂饭，18-21→睡前，等）
- 场景库：留给 Discover 页，Onboarding 只给入口

### 参考依据
- 芭芭农场：单株成长，不做花圃地图
- Parent Sense：Responsive Routine 根据实时数据调整

## 3. 第一句练习

### 讨论过程
- V20 方案：句卡有圆角边框和阴影
- 设计师意见：卡片感让用户倾向"先读完"，不是"看到就说"
- 用户确认：去掉边框，英文直接浮出

### 最终确认
- 句卡：无边框，英文直接浮在页面上
- 发音播放：从独立按钮弱化为小图标（🔊）
- 主按钮："说完了"固定底部，≥56px
- 次级按钮："换一句"、"结束"为文字按钮

### 参考依据
- Zoom：行动先于解释，不要教程
- Loom：一键开始，减少摩擦

## 4. 小禾气泡

### 讨论过程
- V20 方案："会说就直接说。"
- 用户反馈：语气像指令，预设了"不会说"的可能
- 设计师建议：去掉气泡 vs 换文案
- 用户选择：换文案保留气泡
- 声源问题：小禾气泡和独立文字引导同时出现，双声不统一
- PM 确认：一个页面只有一个"说话的人"

### 最终确认
- 首屏气泡：`选个正在发生的场景，小禾给你一句现在就能说的。`（统一声源）
- 练习页气泡：场景动态文案（如"睡前轻轻说，像讲故事一样"）
- 去掉独立文字引导（"小禾会根据你选的场景..."、"说完后..."）
- 结束态：小禾气泡和标题说不同的事（气泡=情感鼓励，标题=事实陈述）

### 场景动态文案
- 喂饭：`喂饭时轻轻说，宝宝会听的。`
- 喝水：`递水的时候说一句就好。`
- 换尿布：`换尿布时说，宝宝反而更安静。`
- 洗澡：`洗澡时说，宝宝会觉得好玩。`
- 睡前：`睡前轻轻说，像讲故事一样。`
- 出门：`出门前说一句，今天就开始了。`

## 5. 宝宝反应记录

### 讨论过程
- V20 方案：3 个纯文字按钮，1.35s 自动跳转
- 设计师意见：1.35s 太快，纯文字按钮在分心场景下操作成本高
- 用户确认：采纳两个建议

### 最终确认
- 按钮样式：图标 + 文字组合（😊有回应/😌安静了/😐没反应）
- 自动跳转：延长到 2.5-3 秒，显示可见倒计时进度条
- 可取消：点击"换一句"或"结束"取消自动跳转
- 触觉反馈：选择反应时轻触觉

### 参考依据
- 微交互规则（2026）：即时反馈 < 100ms
- 拇指区域：主要操作在底部 1/3

## 6. 结束态

### 讨论过程
- V20 方案：静态"今天已经很好"文案
- 用户反馈：文案单调，需要视觉效果
- 设计师建议：种子萌芽动画 + 动态文案系统
- 用户确认：采纳萌芽方案

### 最终确认
- 视觉：种子萌芽动画（1.5s，#3B8577 绿色）
- 小禾气泡：按完成数量动态变化（1句/2-3句/4+句）
- 主标题：按场景动态变化（喂饭/睡前/洗澡/出门/喝水/换尿布）
- 总结：固定行 + 可选追加（按宝宝反应）
- 按钮："再来一句" + "先到这里"
- 与 Garden 关联：结束页萌芽 = 花园种子

### 参考依据
- 芭芭农场：种子→发芽→含苞→盛开→结果
- 里程碑庆祝动画 < 300ms（萌芽 1.5s 是例外，因为是里程碑）

## 7. UX 优化（基于行业研究）

### 研究来源
- 15 个成功 App Onboarding 最佳实践（Userpilot 2025）
- 5 条微交互设计规则（DEV Community 2026）
- 移动端 UX 最佳实践（DevEntia Tech 2026）
- Duolingo 首页重设计案例
- Parent Sense / TinyPal / Huckleberry 等育儿 App

### 确认的优化
1. 去掉"开始一句"按钮：场景选中后自动进入练习
2. 声源统一：所有引导融入小禾气泡
3. 首屏价值说明：融入小禾气泡（"小禾给你一句现在就能说的"）
4. 拇指区域：主要操作在底部 1/3

## 8. 微交互规范

### 触觉反馈
- 选中场景：轻触觉 (HapticFeedback.lightTap)
- 点击"说完了"：中触觉 (HapticFeedback.mediumImpact)
- 选择反应：轻触觉

### 按钮动画
- 场景按钮：scale(0.95)，150ms ease-out
- "说完了"：scale(0.97)，150ms ease-out
- 反应按钮：scale(0.95)，200ms ease-out

### 页面转场
- 场景→练习：元素级联动，stagger 50ms，cubic-bezier(0.25, 0.1, 0.25, 1.0)
- 练习→结束：元素级联动，stagger 80ms，萌芽 1.5s

### 转场序列
场景→练习：
1. 选中场景放大高亮 (200ms)
2. 其他场景淡出 (150ms)
3. 小禾气泡切换 (200ms)
4. 英文句子飞入 (300ms)
5. "说完了"推入 (250ms)

练习→结束：
1. "说完了"→"✓ 已保存" (200ms)
2. 反应按钮依次淡入 (stagger 80ms)
3. 萌芽生长 (1.5s)
4. 标题淡入 (300ms)
5. 按钮淡入 (200ms)

### 性能指标
- 触觉响应：< 100ms
- 按钮动画：< 150ms
- 页面转场：< 300ms
- 庆祝动画：< 300ms（萌芽 1.5s 除外）
